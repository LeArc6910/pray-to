# 시스템 공급표

조사 보고서 후보 12(`Docs/Research2026-11.md`, 2026-11-11). pray-to는 시스템이 많아 기능 비대가 가장 큰 구조적 위험이다. Forager 회고의 말대로 "유지보수 없이 기능을 계속 쌓으면 게임이 자기 무게에 무너진다". 그래서 시스템마다 **무엇을 어느 시스템에 공급하는지** 표로 둔다. 어디에도 공급하지 않거나 아무것도 받지 않는 고립 기능은 사다리에 잇거나 덜어 낸다.

표는 손으로 쓰지 않고 시트에서 만든다.

```
dotnet run --project DevTools/CoreSandbox -- --supply
```

재료마다 오는 곳(캐기, 사냥, 보스, 농사, 낚시, 동물, 채집, 제작, 공장·가공, 상점, 보답, 장비 분해, 균열)과 가는 곳(장비, 소모품, 기지 짓기, 공장, 농사, 낚시, 동물, 펫, 스킬, 기지 방어, 균열, 부탁, 이야기, 장비 다듬기, 팔기, 상점)을 시트(`materials.csv`, `recipes.csv`, `tiles.csv`, `crops.csv`, `machines.csv`, `monsters.csv`, `bosses.csv`, `shop.csv`, `requests.csv`, `story.csv`)와 코드가 이름으로 쓰는 재료(물뿌리개, 미끼, 사료, 탄환, 결정, 균열 열쇠, 알 등)로 센다. 새 시스템이나 재료를 더하면 다시 돌려 아래 "고립" 목록이 비어 있는지 본다.

## 고립 점검 (2026-11-11)

- **얻지만 쓰는 곳이 없던 것**: 장군의 문장(미쳐 버린 장군 모르그가 떨어뜨리는 증표) 하나였다. 왕실 상인 엘라가 400금화에 사게 했다(`shop.csv`). 이제 0
- **쓰지만 얻는 곳이 없는 것**: 없다
- **팔기에만 가는 것**(8): 가공품 여섯(서리 주스, 별 수박 술, 고추 절임, 공허 콩 절임, 마요네즈, 치즈), 동굴 달팽이, 장군의 문장. 가공품은 돈벌이로 설계한 것이라 그대로 둔다. 다만 술통·절임 단지가 "돈 말고 다른 시스템"에 닿지 않으므로, 버프 음식이나 부탁 재료로 잇는 것을 다음 후보로 남긴다
- **받기만 하는 쪽**: 이야기·부탁·팔기·펫·스킬·기지 방어는 재료를 받아 경험치, 금화, 보상, 힘을 돌려준다(재료가 아닌 것이라 표에는 들어가지 않는다)

## 읽는 법

- 행이 많이 찬 시스템(사냥, 캐기, 상점, 제작)은 사다리의 기둥이다. 한두 칸만 찬 시스템(균열, 동물, 장비 분해)은 다른 시스템을 거쳐야 의미가 생긴다
- 한 시스템을 늘리기 전에 그 행과 열을 본다. 새 재료가 "팔기"에만 가면 그 시스템은 돈 말고는 아무것도 바꾸지 않는다
