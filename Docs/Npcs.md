# 상인과 호감도

생활 콘텐츠의 첫 사람이다(2026-11-03, 사람이 고른 1~14번 중 11번). 코드는 `Assets/_Project/Scripts/Core/Simulation/World.Merchant.cs`, 시트 읽기는 `Core/World/NpcSheet.cs`, 데이터는 `Assets/_Project/Data/Npcs/`에 있다.

## 한눈에

- 시작 지점 가까이에 **상인 도라의 노점**이 있다. 노점 곁(2.5타일)에 서면 가방에 **[상인]** 탭이 생긴다
- **금화**(`coin`, 재료)로 씨앗, 물약, 귀환 두루마리, 가끔 귀한 것을 사고, 작물, 물고기, 요리, 주괴, 장비를 판다
- 하루에 한 번 **말 걸기**, 한 번 **선물**을 하면 **호감**이 오른다. 호감이 오를수록 값이 좋아지고 숨겨 둔 물건이 열린다
- 공장이나 사냥만으로 얻을 수 없는 것을 파는 것은 아니다. 손으로 모으기 번거로운 것을 금화로 바꾸는 길이고, 사냥(장비 팔기), 생활(작물·물고기·요리), 공장(주괴)이 모두 금화로 이어진다

## 노점

- 칸 종류 `MerchantStall`. `tiles.csv`에 줄이 없어서 곡괭이로 캐지지 않고 지나갈 수 없다
- 월드를 만들 때(그리고 저장본을 불러온 뒤에도) 지도에 노점이 없으면 시작 지점에서 3~12칸 떨어진, 앞(아래)이 바닥인 바닥 칸에 하나 놓는다(`World.PlaceNpcs`). 시작 지점 바로 옆은 쓰지 않는다
- 바뀐 칸으로 저장되고 나중에 들어온 사람에게도 간다. 그 자리에 무언가를 지어 노점이 덮였다면 불러올 때 다른 자리에 다시 놓는다
- 화면은 노점 뒤에 보라 옷을 입은 상인을 서 있는 플레이어 그림으로 그리고, 카운터를 그 다리 위에 한 번 더 그린다. 가까이 가면 이름과 호감이 뜬다

## 숫자로 본 벌이 (2026-11-04, `dotnet run --project DevTools/CoreSandbox -- --economy`)

시간당 금화(호감 0일 때):

| 벌이 | 시간당 |
|---|---|
| 흙 동굴 낮 낚시(손으로) | 약 680 (밤 1700) |
| 얼음·수정·심연 낚시 | 1100~1650 |
| 딸기 밭 8칸(스프링클러, 술통으로 주스) | 약 360 |
| 밭 한 칸 | 그대로 18~42, 가공하면 27~72 |
| 닭 한 마리(마요네즈) | 33, 사료 값 빼고 24쯤 |
| 통발 하나 | 27, 미끼 값 빼고 19쯤 |
| 장비 하나 팔기 | 레벨 10에 평균 10, 20에 17, 40에 31 |

그래서 닭(120)은 반 시간, 균열 열쇠(800, 호감 3)는 낚시로 한 시간쯤이다. 낚시가 손이 가는 만큼 가장 벌이가 좋고, 밭·닭장·통발은 다른 일을 하는 동안 저절로 번다.

## 사고팔기

- **사기**: 오늘 파는 물건(`World.ShopFor`)을 금화로 산다. `shop.csv`에서 `buy`가 있는 줄 가운데 `daily`가 아닌 것은 늘 있고, `daily`인 것은 날마다 **두 가지**(`World.DailyShopItems`)만 나온다. 고르는 것은 그날의 날짜만으로 정해서 모든 클라이언트가 같게 본다
- **팔기**: `sell`이 있는 재료와 소모품을 하나씩 또는 모두 판다. 가방의 장비(입은 것은 빼고)도 판다. 장비 값은 `(4 + 레벨) × 등급값 / 2 + 강화 × 5`이고 등급값은 일반 1, 고급 2, 희귀 3, 영웅 5, 전설 8이다
- **호감과 값**: 호감 하나마다 사는 값은 4% 싸지고(올림) 파는 값은 4% 비싸진다(내림, `World.HeartPercent`). 호감 5면 20%다
- **호감으로 열리는 물건**: `hearts`가 있는 줄은 그만큼 호감이 있어야 산다. 지금은 공허 콩 씨앗·닭(호감 1), 강화 정수(호감 2, 오늘 파는 날만), 균열 열쇠(호감 3, 800금화)
- 한 번에 99개까지(`World.MaxTrade`)

## 호감

- 0~500점, 100점마다 호감 하나(최대 5, `World.MaxHearts`)
- **말 걸기**: 하루 한 번 +10. 그날의 대사가 탭 위에 보인다(대사는 날짜와 호감으로 고른다)
- **선물**: 하루 한 번, 가진 재료나 소모품 하나(금화는 빼고). 아주 좋아하는 것 +80, 좋아하는 것 +45, 보통 +20, 싫어하는 것 -20(0 아래로는 내려가지 않는다). 무엇을 좋아하는지는 미리 알려 주지 않는다. 주면 머리 위에 반응이 뜬다
- 하루는 `Docs/Time.md`의 날(20분)이다. 잠을 자서 날이 바뀌면 다시 할 수 있다
- 호감은 **캐릭터에** 남는다(캐릭터 저장본 형식 5). 그래서 다른 월드에 가도 같은 상인을 같은 만큼 안다

## npcs.csv

`Assets/_Project/Data/Npcs/npcs.csv`. 한 줄이 한 사람이다.

| 열 | 내용 |
|---|---|
| id | 영문 id. 캐릭터 저장본이 이 id로 호감을 기억한다 |
| name | 화면에 보이는 이름 |
| tile | 그 사람이 서 있는 칸 종류. 지금은 `MerchantStall`(상인) |
| loves, likes, dislikes | 아주 좋아하는 것, 좋아하는 것, 싫어하는 것. 재료나 소모품 id를 `\|`로 잇는다 |
| lines | 대사. `\|`로 나눈다. 쉼표는 쓰지 않는다 |

## shop.csv

`Assets/_Project/Data/Npcs/shop.csv`. 한 줄이 한 물건이다.

| 열 | 내용 |
|---|---|
| item | 재료나 소모품 id |
| buy | 상인이 파는 값(금화). 비우면 팔지 않는다 |
| sell | 상인이 사 주는 값. 비우면 사지 않는다. `buy`보다 작아야 한다(사서 되팔아 벌 수 없게) |
| daily | `yes`면 날마다 몇 가지만 나오는 물건 |
| hearts | 사려면 있어야 하는 호감(0~5). 비우면 0 |

## 통신과 저장

- 명령: `Buy`(Index가 `shop.csv`의 줄, Item이 개수), `Sell`(Index가 시트 번호, Item이 `StackKind + 4 × 개수`), `SellItem`(아이템 id), `Gift`(Item이 `StackKind`, Index가 시트 번호), `Talk`. 호스트는 노점 곁에 있는지, 오늘 파는지, 호감이 되는지, 금화가 있는지를 다시 본다
- `FriendshipsMessage`: 그 플레이어의 사람마다 점수와 마지막으로 이야기한 날, 선물한 날. 바뀌었을 때만 간다. 클라이언트는 이것을 캐릭터 저장본에 적는다
- 선물과 말 걸기는 `Npc` 사건(Amount가 반응, Target이 사람 번호)으로 화면에 반응을 띄운다
- `Protocol.Version` 0.38.0

## 아직 정하지 않은 것

- 상인 말고 다른 사람(대장장이, 어부), 그 사람마다의 부탁(퀘스트)과 호감 보상
- 금화를 몬스터가 떨어뜨릴지(지금은 팔아서만 번다)
