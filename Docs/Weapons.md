## 무기 종류 (`Data/Loot/weapon_kinds.csv`)

피해는 무기마다 `item_bases.csv`에 적고, 같은 구간에서 **초당 피해가 비슷하게** 맞췄다(시험 `WeaponTests.TheKindsOfAStepDealAboutTheSameASecond`). 종류는 사거리·속도·모양으로 다르다. 속도는 기본 공격 횟수의 배율(1 = 초당 2번)이다.

| 갈래 | 종류 | 기본 공격 | 속도 | 피해(검·활·지팡이 대비) | 특징 |
|---|---|---|---|---|---|
| 근접 | 검 | 120° 부채꼴, 1.1칸 | 1 | 1 | 균형 |
| | 단검 | 90°, 0.8칸, 밀침 0.7 | 1.6 | 0.6, 치명 +8 | 빠르고 짧음 |
| | 대검 | 160°, 1.4칸, 밀침 1.5 | 0.6 | 1.7 | 넓고 셈 |
| | 창 | 30°, 1.9칸 | 0.85 | 1.15 | 길고 좁게, 줄지은 적 모두 |
| | 망치 | 100°, 1칸, 밀침 1.3 | 0.5 | 1.9 | 마무리 일격(3단)이 0.6초 기절 |
| 원거리 | 활 | 초당 16칸, 8칸 | 1 | 1 | 균형 |
| | 석궁 | 초당 24칸, 10칸, 하나 관통 | 0.45 | 2.2 | 한 발이 셈 |
| | 부메랑 | 초당 12칸, 5칸 갔다 돌아옴 | 0.6 | 0.85 | 오가며 두 번 맞힘 |
| 마법 | 지팡이 | 초당 11칸, 7칸 | 1(공속 −15% 그대로) | 1 | 균형 |
| | 완드 | 초당 14칸, 6칸, 가는 탄 | 1.75 | 0.49 | 빠른 연사 |
| | 오브 | 초당 9칸, 4칸, 닿은 곳에서 1.3칸 폭발 | 0.68 | 1.2 | 무리에 강함 |
| 없음 | 곡괭이 | 검과 같음 | 1 | - | 캐기. 클래스 무기로 치지 않는다 |

- **연타**: 세 종류 모두 3단 연타를 그대로 한다. 마무리 일격은 휘두르기면 제 각도 +50°(검 170°), 사거리 +0.9칸, 쏘기면 탄이 1.6배 굵다
- **기절**: 망치의 마무리 일격은 공격 시트로 싸우는 몬스터를 0.6초 비틀거리게 한다(`World.Daze`, 비틀거리는 동안 피해 1.5배, 보스는 안 걸린다)
- **시트 열**: `id,name,branch(melee/ranged/magic/비움),attack(swing/arrow/bolt),speed,reach,arc,push,stun,shot_speed,range,radius,pierce,returns(yes),burst,description`. 시트가 없으면 검·활·지팡이·곡괭이 기본값(예전과 같다). `item_bases.csv`의 `kind` 열이 종류 id이고, 비우면 태그·도구로 정한다(`WeaponKind.DefaultFor`)

## 스킬이 힘을 받는 규칙

- 클래스마다 무기 갈래가 있다(`classes.csv`의 `weapon`): 전사 근접, 궁수 원거리, 화염 마법사·폭풍술사·소환사 마법
- 클래스 스킬은 **장착한 제 갈래 무기**의 공격 능력치로 계산한다(`PlayerStats.ForSkill`). 손에 든 것과 상관없다. 두 칸이 다 맞으면 손에 든 쪽을 쓴다
- 맞는 갈래 무기가 없으면 두 무기 가운데 센 쪽의 **80%**(`PlayerStats.OffBranchShare`). 스킬 툴팁에 "근접 무기의 힘을 받는다" 또는 "근접 무기 없음: 더 센 무기의 80%로 친다"가 붙는다
- 곡괭이와 맨손은 어느 갈래도 아니다
- 클래스 셋이 갈래 셋(예: 전사+궁수+화염 마법사)이면 칸이 둘뿐이라 한 갈래가 80%다

**클래스 보너스**: 패시브는 이미 태그에 걸려 있어(전사 근접 +10%, 궁수 원거리 +15% 등) 숫자는 그대로다. 스킬이 제 갈래 무기로 계산되니 다른 무기를 들어도 보너스가 붙는다. 바뀐 것은 궁수의 공격 속도 하나다: 모든 공격 +10% → **원거리 공격 속도 +10%**.
