# 퀘스트 창과 HUD 꾸미기 (3a, 2026-11-27)

사람이 시안을 보고 "그대로 진행"(2026-11-27). 시안: 반투명 남색 판 + 겹 금테 + 모서리 마름모.

- HUD의 칸(상태 막대 칸, 퀘스트 창 펼친·접힌 모양, 퀵슬롯 칸, 미니맵 테두리, 획득 알림 줄)이 모두 시작화면의 판(`TitleArt.Panel`: 비치는 밤색, 금테, 모서리의 박힌 돌)을 쓴다: `UiSkin.HudPanel`
- 퀘스트 창(펼친 모양): 항목마다 왼쪽 아이콘(장 = 책, 목표 = 별, 이야기 = 집, 부탁 = 상자), 금색 제목, 장 제목 아래 금색 줄, 본문, 본문에 "n/m"이 있으면 그 진행 막대(다 차면 초록), 보상·보답은 상자 아이콘과 금색 줄로 따로. 접기·펴기와 휴대폰 세로의 한 줄 모양은 그대로(`GameRoot.cs`의 `DrawTracker`, `CountIn`, `SplitReward`)
- 생명력·마나·경험치 막대는 그대로(금테 우물 안의 막대), 판만 바뀜. 퀵슬롯에는 "고른 칸"이 없어 밝은 금테 강조는 하지 않았다
