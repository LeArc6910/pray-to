# 보스

M3에서 만든 보스전 규칙과 시트 작성법이다. 코드는 `Assets/_Project/Scripts/Core/Simulation/World.Boss.cs`와 `BossSheet.cs`, 데이터는 `Assets/_Project/Data/Bosses/`에 있다.

## 흐름

1. **아레나**: 월드를 만들 때 시작 지점에서 약 38칸 떨어진 곳에 반지름 10칸짜리 둥근 방을 파고, 폭 3칸 굴로 잇는다. 바닥이 붉은 색이라 알아볼 수 있고, HUD에 방향과 거리가 나온다.
2. **잠듦**: 보스는 아레나 가운데에서 잔다. 플레이어가 아레나 안으로 들어오거나 보스를 때리면 깬다.
3. **체력 보정**: 깨어날 때 살아 있는 플레이어 수로 최대 체력을 정한다. 한 명 늘 때마다 `health_per_player`%씩 늘어난다.
4. **공격 고르기**: 지금 페이즈에서 쓸 수 있는 공격 중 `weight` 비율로 하나를 고른다. 사거리가 필요한 공격(부채꼴, 직선, 돌진)이면 대상에게 다가가고, 3초 안에 닿지 못하면 그 자리에서 쓴다.
5. **예고**: `telegraph`초 동안 바닥에 맞을 곳을 표시하고 보스는 멈춰서 빛난다. 원형은 대상이 **그때 서 있던 곳**에 생기므로 움직이면 피할 수 있다.
6. **발동**: 예고가 끝나면 표시된 곳 안의 플레이어가 맞는다. 투사체는 날아가고, 돌진은 표시된 길을 달린다.
7. **휴식**: `cooldown`초 쉰 뒤 다시 4번으로 간다.
8. **페이즈 전환**: 체력이 `phases`에 적힌 비율 아래로 떨어지면 다음 페이즈로 넘어간다. `roar`초 동안 포효하며 피해를 받지 않고, 끝날 때 주변 `roar_radius` 안을 `roar_damage`로 친다. 붙어 있던 플레이어는 물러나야 한다.
9. **전멸과 초기화**: 아레나 근처(아레나 반지름 + 6칸)에 살아 있는 플레이어가 5초 동안 없으면 보스가 처음 상태로 돌아가 다시 잠든다. 혼자 하다 쓰러지면 부활 지점이 멀어서 사실상 다시 도전해야 한다.
10. **처치**: 보상을 떨어뜨리고 사라진다. 진행 레벨이 올라가서 이후 드랍이 다음 단계 장비가 된다(`Docs/Loot.md`의 드랍 절). `BossRespawnSeconds`(지금 120초) 뒤 다시 아레나에 나타난다.

## 공격 모양

| shape | 하는 일 | 쓰는 열 |
|---|---|---|
| `circle` | 대상 위치에 원. `count`가 2 이상이고 `spread`가 있으면 대상 주변에 흩어져 떨어진다 | radius, count, spread |
| `cone` | 보스 앞쪽 부채꼴 | length, angle |
| `line` | 보스에서 뻗는 직선 광선 | length, width |
| `charge` | 표시된 길을 따라 돌진하고, 부딪힌 플레이어를 한 번씩 친다. 벽에 막히면 멈춘다 | length, width, speed |
| `burst` | 투사체를 쏜다. `angle`이 비어 있으면 사방으로, 있으면 대상 쪽으로 그 각도만큼 펼쳐 쏜다. 벽이나 플레이어에 닿으면 사라진다 | count, speed, radius, angle |
| `summon` | 보스 주변 `spread`칸 거리에 몬스터를 부른다 | count, spread, summon |

대상(`target`)은 `nearest`(가장 가까운 사람), `farthest`(가장 먼 사람), `random`, `each`(싸우는 사람마다 하나씩), `self`(보스 자신 중심) 중 하나다. `farthest`와 `each`는 협동할 때 의미가 생긴다. 멀리서 활 쏘는 사람도 안전하지 않고, 모두가 각자 피해야 한다.

## bosses.csv

| 열 | 내용 |
|---|---|
| id, name | id와 화면 이름 |
| health | 혼자일 때 체력 |
| health_per_player | 한 명 늘 때마다 늘어나는 체력(%) |

| phases | 다음 페이즈가 시작되는 체력 비율. 큰 수부터 `|`로 나눈다. `66|33`이면 3페이즈 |
| roar, roar_radius, roar_damage | 페이즈 전환 포효 시간(초)과 끝날 때 폭발의 반지름과 피해 |
| drop_count, rune_count | 싸운 사람 한 명마다 떨어뜨리는 아이템, 룬 수 |

| material, material_count | 싸운 사람 한 명마다 떨어뜨리는 재료 id와 수. 동굴 수호자는 철 장비를 만드는 수호자의 핵 1개 |
| element | (선택) 모든 공격의 원소: `fire`(화상), `cold`(느려짐), `lightning`. 비우면 없음(`Docs/Combat.md`의 "원소") |
| drop_level | 보상 아이템의 레벨. 잡은 뒤로는 모든 드랍이 이 레벨 이상이 된다 |
| drop_rarity | 보상 아이템의 최소 등급(`common`, `uncommon`, `rare`, `epic`) |

## boss_attacks.csv

한 줄이 공격 하나다. 열은 `boss, id, name, phases, shape, target, telegraph, damage, radius, length, angle, width, count, spread, speed, cooldown, weight, summon`이다.

- `phases`: 이 공격을 쓰는 페이즈를 `1|2`처럼 적는다. 비워 두면 모든 페이즈에서 쓴다.
- 모양마다 위 표의 열은 꼭 채워야 하고, 나머지는 비워 둬도 된다. 빠진 열이 있으면 테스트가 `boss_attacks.csv 5행: Charge 공격에는 ... speed이 필요합니다`처럼 알려준다.
- 페이즈마다 쓸 수 있는 공격이 하나는 있어야 한다.

## 동굴 수호자 (첫 보스)

| 페이즈 | 쓰는 공격 |
|---|---|
| 1 (체력 100~66%) | 내려찍기(원), 휩쓸기(부채꼴), 돌 파편(사방 10발) |
| 2 (66~33%) | 내려찍기, 휩쓸기, 돌 파편, 지진(모두의 발밑에 원), 돌진(가장 먼 사람에게) |
| 3 (33% 이하) | 내려찍기, 휩쓸기, 지진, 돌진, 돌 폭풍(사방 18발), 낙석(대상 주변에 원 4개), 슬라임 부르기 |

## 수정 거미 여왕 (두 번째 보스, 2026-11-01)

깊은 곳(시작 지점에서 60칸 넘게 먼 모퉁이)의 **깊은 아레나**에 있다. 월드를 만들 때 첫 아레나 쪽 모퉁이(시작 지점에서 가로·세로로 약 50칸)에 같은 크기의 방을 파고, 첫 아레나에서 굴로 잇는다. 그래서 길은 시작 지점 → 동굴 수호자 → 수정 거미 여왕으로 이어진다. 시트의 보스 순서가 아레나 순서다(`GeneratedWorld.Arenas`). 아레나와 미스릴 광맥은 따로 된 난수로 만들어서, 이미 있던 시드의 동굴·첫 아레나·구리·철 광맥은 그대로다.

| 페이즈 | 쓰는 공격 |
|---|---|
| 1 (체력 100~66%) | 물어뜯기(가까운 사람에게 부채꼴), 수정 비(아무 데나 원 5개), 수정 가시(사방 12발) |
| 2 (66~33%) | 물어뜯기, 수정 비, 수정 가시, 덮치기(가장 먼 사람에게 돌진), 거미줄 진동(모두의 발밑에 원) |
| 3 (33% 이하) | 물어뜯기, 수정 비, 덮치기, 거미줄 진동, 수정 폭풍(사방 20발), 박쥐 부르기(수정 박쥐 3마리) |

- 체력 1300(한 명 늘 때마다 130%씩 더), 방어도 20. 잡으면 미스릴 단계(레벨 20) 희귀 장비 3개, 룬 2개, 물약 3개, **수정 심장** 1개를 떨어뜨리고 진행 레벨이 20이 된다
- 샌드박스(봇 1명, 철 장비 네 벌, 전사 + 화염 마법사, 시드 1~3): 반응 0.25초면 50~60초에 잡고 거의 맞지 않는다. 반응 0.5초(사람에 가까운 늦음)면 50~58초에 잡고 120~260을 맞으며 물약을 1~3개 마신다. 같은 조건의 동굴 수호자(구리 장비)는 42초에 18을 맞는다. 맞는 피해는 대부분 물어뜯기다. 확인 명령: `dotnet run --project DevTools/CoreSandbox -- --boss 400 1 --boss-id crystal_queen --gear iron_sword,iron_helmet,iron_armor,iron_boots --classes warrior,fire_mage --reaction 0.5`

## 용암 거인 (세 번째 보스, 2026-11-01)

사람이 고른 다음 작업 중 "흑요석 단계와 세 번째 보스"다. 표에만 있던 흑요석 장비(레벨 30)로 가는 길을 열었다.

- **어디**: 깊은 아레나 반대쪽 모퉁이, 용암 지대(`Docs/Biomes.md`) 안의 용암 아레나. 시작 지점에서 곧장 굴이 이어진다. HUD는 "용암 아레나"로 가리킨다
- **모습**: 동굴 수호자와 같은 골렘 몸집을 검은 현무암으로, 몸의 금과 가슴의 핵이 용암처럼 빛난다
- **불**: 모든 공격이 불이라(`bosses.csv`의 새 `element` 열) 맞으면 화상을 입는다(맞은 피해의 30%를 3초에 걸쳐). 버섯 수프(체력)나 냉기 저항 같은 대비가 쓸모 있다
- **공격**(`boss_attacks.csv`): 내려찍기, 불꽃 휩쓸기, 유성 낙하(5곳), 용암 고리(1·2페이즈), 돌진·분화(2·3페이즈), 용암 폭풍과 용암 슬라임 부르기(3페이즈)
- **보상**: 레벨 30(흑요석) 장비 드랍, 용암 심장 1개(흑요석 장비 재료), 진행 레벨 30
- **숫자**: 체력 2400(한 명 늘 때마다 130%씩 더), 방어도 30. 처음에 넣은 240%는 2인일 때 체력이 3.4배가 되어 수정 거미 여왕(130%)에 맞췄다(2026-11-02)
- 샌드박스(봇 1명, 미스릴 장비 네 벌, 전사 + 화염 마법사, 시드 1~3): 반응 0.25초면 55~61초, 반응 0.5초면 49~106초에 160~466을 맞고 물약 2~3개, 한 시드는 한 번 쓰러진다. 같은 조건의 수정 거미 여왕(철 장비)은 58초에 234다. 확인 명령: `dotnet run --project DevTools/CoreSandbox -- --boss 400 1 --boss-id lava_titan --gear mithril_sword,mithril_helmet,mithril_armor,mithril_boots --classes warrior,fire_mage --reaction 0.5`

## 공허의 군주 (최종 보스, 2026-11-02)

사람이 고른 다음 작업 중 "더 깊은 곳"이다. 흑요석 다음 단계(레벨 40, 공허)를 연다.

- **어디**: 공허의 심연(`Docs/Biomes.md`)의 아레나. 용암 아레나에서 굴이 이어진다. `bosses.csv`의 넷째 줄이 넷째 아레나에 선다
- **모습**: 바닥 위에 뜬 두건 쓴 망토, 두건 속 차가운 두 눈, 앞에 든 공허의 구슬, 머리 둘레를 도는 별
- **냉기**: 모든 공격이 냉기라 맞으면 잠시 느려진다
- **공격**: 공허의 손아귀(부채꼴), 별똥별(8곳), 공허 광선(1·2페이즈, 직선), 공허 고리(1·2페이즈), 돌진·붕괴(2·3페이즈, 붕괴는 사람마다 하나), 공허 폭풍과 정령 부르기(3페이즈)
- **보상**: 레벨 40(공허) 장비 드랍, 공허의 정수 1개(공허 장비 재료), 전설 둘(공허 군주의 홀, 공허의 고리), 진행 레벨 40
- **숫자**: 체력 5200(한 명 늘 때마다 130%씩 더), 방어도 40, 포효 40
- 샌드박스(봇 1명, 흑요석 장비 여섯 벌, 전사 + 화염 마법사, 시드 1~3): 반응 0.25초면 61~66초에 65~119를, 반응 0.5초면 63~65초에 121~253을 맞는다(물약 0~2개). 궁수 + 폭풍술사는 64~69초. 2인은 65~71초. 같은 조건의 용암 거인(미스릴 장비)은 52~63초에 37~44, 반응 0.5초에 183~200이다. 확인 명령: `dotnet run --project DevTools/CoreSandbox -- --boss 400 1 --boss-id void_lord --gear obsidian_sword,obsidian_armor,obsidian_helmet,obsidian_boots,obsidian_ring,obsidian_amulet --classes warrior,fire_mage --reaction 0.5`

## 조정하는 법

`dotnet run --project DevTools/CoreSandbox -- --boss 300 42`를 실행하면 봇 파티가 보스와 싸운 결과가 나온다. 처치 시간, 전멸 횟수, 페이즈별 시작 시각, 공격별로 받은 피해를 보여준다.

- `--players 2`: 봇 수
- `--gear copper_sword,copper_armor,copper_helmet,copper_boots`: 장비 (기본은 구리 검만)
- `--reaction 0.4`: 예고를 알아차리는 데 걸리는 시간(초). 사람은 대략 0.25~0.4초다
- `--no-dodge`: 피하지 않는다

지금 숫자(구리 일반 장비 네 부위 기준):

- **혼자**: 반응 0.25초면 시드에 따라 약 절반이 1~3분 안에 잡는다. 반응 0.4초도 비슷한 결과가 나왔다. 피하지 않으면 못 잡는다.
- **2명**: 약 93초. **4명**: 약 70초.
- 쓰러지는 이유는 공격 하나보다 여러 공격의 작은 피해가 쌓이는 경우가 많다. 아직 회복 수단(음식, 물약)이 없어서다.

봇은 투사체를 단순하게 피하고 공격 사이 빈틈을 노리지 않아서, 실제 난이도는 직접 해 보고 맞춘다. 근접으로 붙어 있을 때 예고 안에 벗어날 수 있는지가 핵심이다. 처음에는 휩쓸기(0.7초, 길이 4.5)와 내려찍기(0.9초, 반지름 2.2)가 근접 거리에서 피할 수 없어서 각각 0.9초·길이 3.5, 1.0초·반지름 2.0으로 바꿨다.
