# 월드의 흐름

조사 보고서 후보 24(`Docs/Research2026-11.md`, 2026-11-11). 잘 된 게임은 "손으로 만든 작은 조각 + 규칙에 따른 배치"로 시드가 달라도 흐름을 보장한다(Dead Cells의 생물군계 그래프). pray-to는 시작 지점 → 광맥 → 장소 → 첫 보스 아레나로 이어지는 흐름을 이미 월드 생성기가 정해 놓고 있어서, 먼저 시드마다 그 흐름이 지켜지는지 재고 시험으로 묶었다.

```
dotnet run --project DevTools/CoreSandbox -- --flow [시드,시드,...]
```

시작 지점에서 **파지 않고 걸어서** 몇 걸음(한 칸 한 걸음)에 닿는지다. "-"는 걸어서 못 가는 곳(파고 가야 함). 장소는 웨이포인트 바로 아래 칸까지.

## 읽은 것

- 512칸(2026-11-11): 구리 광맥은 그대로 9~21걸음(광맥 수가 넓이만큼 늘었다), 철 광맥 125~152걸음, 첫 보스 아레나 152~216걸음, 장소는 266~365걸음. 장소끼리는 웨이포인트로 오간다. 시작 60걸음 안에는 흙 동굴 하나만 보인다(128칸 때 5~6가지)
- 128칸 때: 구리 광맥은 10~32걸음, 첫 보스 아레나는 38~54걸음, 왕도는 36~60걸음. 시드마다 크게 다르지 않다
- 일곱 장소 모두 걸어서 닿는다(길이 이어 준다, `Docs/Story.md` 길가)
- 시작 지점에서 60걸음 안에 생물군계가 5~6가지나 보인다. 첫 30분에 정보가 많은 쪽이라, 줄일지는 첫 30분 사람 확인(`LOCAL_TASKS.md` 118단계)과 함께 본다

## 지키는 시험

`WorldMapTests.EverySeedLeadsFromCopperToTheArenaAndEveryPlace`: 시드 1~8에서 구리 광맥 35걸음 안, 첫 아레나 60걸음 안(걸어서), 모든 장소가 걸어서 닿는지. 월드 생성을 고쳐 이 흐름이 깨지면 시험이 실패한다.

## 하지 않은 것

- 생물군계마다 흐름 그래프(입구·특수 방·아레나와 거리)를 시트로 두고 생성기가 그대로 놓게 하는 것, 확률 칸 방 틀, 경계 거칠기 매개변수는 월드 생성을 크게 고치는 일이라(옛 저장본의 월드와도 달라진다) 하지 않았다. 지금 흐름이 시드마다 고르게 지켜지고 있어서 급하지 않다
