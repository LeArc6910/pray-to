# 전투와 몬스터

M2에서 만든 월드, 이동, 전투 규칙이다. 코드는 `Assets/_Project/Scripts/Core/World`와 `Core/Simulation`에 있다.

## 월드

- 시드로 동굴을 만든다. 128×128 타일이고, 무작위로 채운 뒤 다듬어서 시작 지점에서 갈 수 없는 동굴은 메운다(`WorldGenerator`).
- 정수 연산만 쓰기 때문에 같은 시드면 어느 컴퓨터에서나 같은 지도가 나온다. 그래서 호스트는 지도를 보내지 않고 시드만 보낸다.
- 좌표 단위는 타일이다. 타일 (x, y)는 x~x+1, y~y+1을 차지하고, y는 위쪽이 +다.

## 이동과 충돌

- 움직이는 것은 모두 원이다. 플레이어 반지름은 0.35, 몬스터는 시트에 적는다(최대 0.45. 한 칸 통로를 지나가야 한다).
- 벽에 부딪히면 멈추지 않고 벽을 따라 미끄러진다. 붙어 있는 벽 타일은 한 면처럼 다뤄서 이음매에 걸리지 않는다.
- 몬스터는 플레이어를 향하는 길찾기 지도(`FlowField`)를 따라 벽을 돌아서 온다. 0.33초마다 다시 계산한다.

## 플레이어 능력치

장비의 능력치를 `Docs/Loot.md`의 계산식으로 더한다. 기본값은 다음과 같다.

| 능력치 | 기본값 |
|---|---|
| 최대 생명력 | 100 |
| 이동 속도 | 초당 5타일 |
| 공격 속도 | 초당 2회 |
| 피해 | 무기 없음 1, 무기를 들면 무기 능력치만 |
| 치명타 확률 | 5% |
| 치명타 피해 | 150% |
| 최대 마나 | 100 (스킬에 든다, `Docs/Classes.md`) |
| 마나 재생 | 초당 5 |

공격 태그는 무기 베이스의 `tags`를 따르고, 맨손이면 근접(`Melee`)이다. 지금은 시작할 때 구리 검(일반 등급)을 준다.

## 전투 규칙

- **기본 공격**: 공격 버튼을 누르고 있으면 공격 속도에 맞춰 계속 공격한다. 모양은 든 무기 베이스의 태그로 정한다(`BasicAttack`). 태그가 여럿이면 근접, 원거리, 마법 순서로 앞의 것을 따른다.

| 무기 태그 | 기본 공격 | 하는 일 |
|---|---|---|
| 근접(검, 맨손) | 휘두르기 | 바라보는 방향 120° 부채꼴 안에서, 플레이어 몸 가장자리부터 1.1타일 안에 닿는 적을 모두 맞힌다 |
| 원거리(활) | 화살 | 바라보는 쪽으로 초당 16타일, 8타일까지 날아가 처음 닿는 적 하나를 맞힌다 |
| 마법(지팡이) | 마법 탄 | 초당 11타일, 7타일까지. 화살보다 굵고 느리다. 처음 닿는 적 하나를 맞힌다 |

- **쏘는 공격**: 쏠 때 피해와 치명타를 정하고, 맞는 적의 방어도를 그때 뺀다. 다른 플레이어는 통과하고 벽에 닿으면 사라진다. 버프가 준 태그도 실린다(불꽃 부여를 켜면 화살도 화염 공격이고 주황으로 보인다). 활과 지팡이는 멀리서 칠 수 있는 대신 무기 피해가 검보다 낮다(`Docs/Loot.md`의 무기 베이스).
- **피해**: `피해 × (치명타면 치명타 피해%) × 100 / (100 + 방어도)`를 반올림하고, 최소 1이다. 방어도 100이면 피해가 절반, 300이면 4분의 1이 된다.
- **넉백**: 맞은 적은 맞은 곳 반대쪽으로 약 1타일 밀려난다(쏘는 공격은 날아온 쪽 반대로).
- **연타** (2026-11-04, 사람 요청: 평타가 단조롭다): 기본 공격은 3단 연타다(`World.ComboSteps`). 앞 공격의 회복이 끝나고 0.6초(`World.ComboWindowSeconds`) 안에 다시 치면 다음 단계로 이어지고, 그보다 늦으면 1단부터 다시 한다
  - 1단 내려베기, 2단 올려베기(호가 반대로 그려지고 무기도 반대로 돈다), **3단 마무리 일격**: 피해 150%(`World.FinisherDamagePercent`), 휘두르기는 170° 부채꼴에 0.3타일 더 멀리 닿고 1.8배 밀어낸다. 활·지팡이는 탄이 1.6배 굵고 피해 150%. 마무리 뒤에는 회복이 30% 길다
  - 벽이나 광맥을 캐면 연타가 아니다(늘 1단, 보통 속도). 그래서 채굴 속도는 그대로다
  - 공격 사건(`Attack`)의 수는 `종류 + 4 × 단계`다(`World.AttackKindOf`, `World.ComboStepOf`). 통신 버전 0.47.0
  - 봇 결과(구리 검 혼자 동굴 수호자): 전사+화염 41.5→40.1초, 궁수+소환사 43.0→38.4초, 전사 55.2→52.2초. 마나로 느려진 만큼쯤 다시 빨라졌다
- **타격감** (화면만, 2026-11-04. 사건마다 무엇이 일어나는지는 `Docs/Feel.md`의 표, 조각마다 켜고 끄기는 `Client/Feel.cs`)
  - 맞는 곳에 하얀 별(치명타는 금색, 내가 맞으면 빨강)이 터지고, 맞은 몸이 때린 쪽 반대로 살짝 밀렸다 돌아온다(마무리 일격과 치명타는 더 멀리)
  - 내가 친 것이 맞으면 화면이 조금 흔들린다(보통 약하게, 치명타·마무리 일격은 더). 치명타와 마무리 일격은 화면을 0.06초 멈춘다(히트 스톱)
  - 내가 맞으면 맞은 양(최대 생명력 대비)만큼 화면이 흔들리고 가장자리가 붉게 빛난다
  - 마무리 일격은 더 크게 휘두르는 호, 두 배로 내딛는 몸, 낮은 휘두름 소리(`Heavy`)와 무거운 타격음(`Thump`)을 낸다. 1단은 무기를 들었다 내려치고, 2단은 반대로, 3단은 두 팔을 들었다 내려친다
  - 메뉴의 "화면 흔들림"을 끄면 흔들림과 히트 스톱이 함께 꺼진다(별과 넉백은 남는다)
- **적의 공격**: 적은 사거리(`reach`) 안에 들어오면 멈춰서 `windup`초 동안 공격을 예고한다. 화면에서는 빨갛게 깜박인다. 예고가 끝날 때 플레이어가 아직 사거리(+0.2) 안에 있으면 맞는다. 예고 중에 물러나면 피할 수 있고, 이것이 전투의 기본 손맛이다.
- **죽음**: 플레이어는 생명력이 0이 되면 5초 뒤 시작 지점에서 생명력을 다 채우고 일어난다. 적은 바로 사라진다(드랍은 아직 없음).
- **생성**: 동굴에 적을 24마리 정도 유지한다. 2초마다 부족하면 하나씩, 시작 지점과 모든 플레이어에게서 12타일 넘게 떨어진 곳에 만든다. 그 자리의 **구역 레벨**보다 `level`이 높지 않은 몬스터 중에서 `weight` 비율로 고른다.
- **구역 레벨**: 시작 지점에서 30타일마다 하나씩 오른다(`WorldConfig.ZoneRing`). 0~30타일은 1, 30~60타일은 2. 그래서 가시 버섯과 동굴 딱정벌레는 철 광맥이 있는 먼 곳에서만 나온다(2026-10-30). 60타일부터는 3이고, 기본 맵(128칸)에서는 네 모퉁이다. 수정 박쥐(빠른 근접)와 수정 정령(원거리)이 거기서만 나오고, 미스릴 광석을 떨어뜨린다(2026-11-01). 기본 맵에는 구역 4인 바닥이 없다(가장 먼 바닥도 90칸이 안 된다). 그래서 생물군계에만 사는 몬스터는 한 구역 일찍 나온다: 레벨 3은 구역 2부터, 레벨 4(공허 정령, 심연 추적자)는 구역 3부터, 제 생물군계 안에서만(`World.Comes`, 2026-11-11 콘텐츠 점검). 생물군계가 이미 무른 동굴 바깥(32칸 너머)에 있어 그 자체가 문턱이다
- **몬스터의 행동**(`behavior`)
  - `melee`: 다가와서 예고한 뒤 친다. 예고가 끝날 때 아직 사거리 안에 있으면 맞는다(슬라임)
  - `ranged`: `keep_distance`보다 가까우면 물러나고, 틈이 `reach` 이하면 예고한 뒤 그때 플레이어가 있던 쪽으로 투사체를 쏜다(초당 `shot_speed`타일, 사거리의 1.5배까지). 투사체는 처음 닿는 플레이어를 맞히고 벽에서 사라진다(가시 버섯)
  - `charge`: 틈이 `reach` 이하면 그 방향으로 노란 길을 예고하고, 예고가 끝나면 그 길로 초당 `charge_speed`타일로 `reach + 2`타일 돌진한다. 부딪힌 플레이어는 한 번씩 맞고, 벽에 막히면 멈춘다. 옆으로 비키면 피한다(동굴 딱정벌레)

## 원소

사람이 고른 다음 작업(2026-11-01) 중 "원소 효과와 저항"이다. 코드는 `Scripts/Core/Simulation/World.Elements.cs`.

- 화염·냉기·번개 태그가 붙은 공격(기본 공격, 스킬, 정령)은 맞힌 몬스터에 원소 효과를 남긴다. 불꽃 부여처럼 태그를 주는 버프도 같다
  - **화염 → 화상**: 맞힌 피해의 30%를 3초에 걸쳐 더 준다. 반 초마다 한 번씩 피해 숫자로 보인다. 새 화상이 남은 화상보다 세면 바꾼다. 화상으로 쓰러져도 불 붙인 사람이 잡은 것이다(떨어뜨리는 것 포함)
  - **냉기 → 느려짐**: 2초 동안 몬스터가 다섯 틱 중 두 틱을 쉬어 움직임과 공격 준비가 40% 느려진다. 보스는 느려지지 않는다
  - **번개 → 연쇄**: 맞은 적에게서 3.5칸 안의 가장 가까운 적 둘에게 피해의 절반이 튄다. 튄 번개는 다시 튀지 않는다. 보스를 맞혀도 둘레 몬스터에게 튄다
- **저항과 약점**(`monsters.csv`의 `resist`): 원소마다 받는 피해를 %만큼 줄이고, 음수면 늘린다. 한 공격에 원소가 여럿이면 가장 약한 쪽으로 계산한다. 75% 이상 저항하면 그 원소의 효과(화상·느려짐)를 받지 않는다
  - 얼음 슬라임·서리 정령: 냉기 75%, 화염 -25%. 가시 버섯·버섯 병정: 화염 -25%. 수정 정령: 번개 50%
- **몬스터의 원소 공격**(`monsters.csv`의 `element`): 냉기면 맞은 플레이어가 1.5초 동안 30% 느리게 움직이고, 화염이면 화상을 입는다(방어도로 줄지 않는다). 얼음 슬라임·서리 정령이 냉기다
- 화면: 불타는 몸은 주황빛으로 깜빡이고, 느려진 몸은 푸르게 보인다(나, 다른 플레이어, 몬스터). 번개가 튀면 노란 번쩍이는 선이 그어진다
- 냉기·번개를 쓰는 길: 새 클래스 폭풍술사(`Docs/Classes.md`), 서리 지팡이(마법·냉기)와 폭풍 활(원거리·번개). 둘 다 철 단계 무기로 작업대에서 철 주괴 3, 수호자의 핵 1과 얼음 결정 4(서리 지팡이) 또는 빛 포자 4(폭풍 활)로 만든다. 접사 "얼어붙은", "번뜩이는"과 서리·불꽃 룬도 이제 쓸모가 있다

## 회복

장비의 생명력 재생 말고 두 가지가 있다(2026-10-29). 회복이 없어서 보스전이 작은 피해 누적으로 끝나기 쉬웠던 것을 푼다.

- **쉬면 차오른다**: 6초 동안 피해를 받지 않으면 초당 최대 생명력의 3%씩 찬다(바닥부터 가득까지 약 33초). 맞으면 다시 6초를 기다린다. 싸움 사이에 기다리는 시간을 줄이려는 것이고, 싸우는 중에는 물약을 쓴다
- **소모품(물약)**: 가방에 종류별로 쌓이고(칸을 차지하지 않는다) 마시면 정해진 초에 걸쳐 최대 생명력의 정해진 %를 채운다. 마신 뒤에는 모든 소모품에 함께 재사용 대기가 걸린다. 생명력이 가득하면 마시지 않는다. 쓰러지면 채우던 것도 멈춘다
  - 회복 물약: 2초에 걸쳐 35%, 재사용 대기 10초
  - 얻는 곳: 시작할 때 3개(`HostConfig.StarterConsumables`). 몬스터는 `potion_chance`% 확률로(슬라임 8%), 보스는 싸운 사람마다 `potion_count`개(동굴 수호자 2개)
  - 마시기: PC는 C, 휴대폰은 스킬 버튼 왼쪽의 물약 버튼, 또는 가방 창의 [마시기]
- 소모품의 숫자는 `consumables.csv`(`Docs/Loot.md`)에 있다. 농사(M5)의 음식도 여기에 들어간다
- 봇 결과(구리 검, 혼자 보스, 시드 1~5): 클래스 없이 다섯 번 중 두 번 못 잡던 것이 한 번으로 줄었다(110초에 잡음). 클래스 둘이면 물약을 거의 마시지 않고 잡는다. 슬라임 사냥 2분에 물약 하나쯤을 줍는다(샌드박스 봇은 생명력이 절반 아래면 마신다)

## monsters.csv

`Assets/_Project/Data/Monsters/monsters.csv`. 한 줄이 몬스터 한 종류다.

| 열 | 내용 |
|---|---|
| id, name | id와 화면 이름 |
| level | 구역 레벨이 이 이상이어야 생성된다 |
| health, damage, armor | 생명력, 한 번 공격의 피해, 방어도 |
| speed | 초당 이동 타일 수 |
| radius | 몸 반지름(타일). 0보다 크고 0.45 이하 |
| aggro | 이만큼 가까운 플레이어를 쫓기 시작한다. 1.5배 넘게 멀어지면 포기한다 |
| reach | 플레이어와의 틈이 이 이하가 되면 공격을 예고한다 |
| windup | 예고 시간(초). 짧을수록 피하기 어렵다 |
| cooldown | 공격 후 다시 쫓기까지 쉬는 시간(초) |
| behavior | `melee`, `ranged`, `charge`. 비우면 melee |
| shot_speed, keep_distance | ranged의 투사체 속도(초당 타일)와 물러나는 거리(타일) |
| charge_speed | charge의 돌진 속도(초당 타일) |
| color | 화면에서 칠할 색, `#RRGGBB`. 비우면 초록 |
| resist | (선택) 원소 저항. `fire:75\|cold:-25`처럼 원소:퍼센트, 음수는 약점, 100까지 |
| element | (선택) 공격의 원소: `fire`(화상), `cold`(느려짐), `lightning`. 비우면 없음 |
| biome | (선택) 이 생물군계에서만 나온다: `cave`, `mushroom`, `ice`, `crystal`, `lava`. 비우면 어디서나(`Docs/Biomes.md`) |
| place | (선택, 2026-11-10) 이야기 장소의 id(`places.csv`). 그 장소 광장 둘레 16칸 안에서만 나오고, 지역 레벨과 생물군계를 따지지 않는다. 그 둘레에서는 이런 몬스터만 나온다. 마족 둥지의 마족 병사·주술사(`Docs/Story.md`) |
| weight | 같은 구역에서 나올 비율 |
| drop_chance, rune_chance | 죽을 때 아이템, 룬을 떨어뜨릴 확률(%). 비우면 0. 자세한 건 `Docs/Loot.md`의 드랍 절 |
| potion_chance | 죽을 때 소모품(물약)을 떨어뜨릴 확률(%). 비우면 0 |
| material, material_chance | 죽을 때 떨어뜨리는 재료 id(`materials.csv`)와 확률(%). 비우면 없음 |

## 조정하는 법

`dotnet run --project DevTools/CoreSandbox -- --fight 120 42`를 실행하면 봇 한 명이 동굴에서 2분 동안 싸운 결과를 보여준다.

- `--gear iron_sword,copper_armor`: 장비를 바꾼다.
- `--no-dodge`: 피하지 않고 맞으면서 싸운다.

지금 숫자(구리 검 기준, 시드 42): 분당 약 11마리를 처치한다. 피하지 않으면 초당 약 0.8의 피해를 받는다. 첫 몬스터라 쉽게 잡아 두었다. 봇은 반응 시간 없이 완벽하게 피하므로, 실제 난이도는 직접 해 보고 `windup`으로 맞춘다.

가시 버섯과 동굴 딱정벌레를 넣은 뒤(2026-10-30, 10분, 시드 42·7): 처치의 약 40%가 새 몬스터이고, 받은 피해는 대부분 동굴 딱정벌레의 돌진이다(구리 검 10분에 56~112). 봇은 예고된 길과 투사체를 0.25초 늦게 알아차리고 옆으로 비킨다. 결과에 몬스터별 처치와 받은 피해가 나온다.
