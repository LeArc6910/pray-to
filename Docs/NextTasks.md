## 2. 월드 묶음 — 새 월드만 (8판 사냥터는 끝남, 2c는 9판, 2a는 10판)

### 2a. 마을·성 다시 만들기 (가장 큼)
사람 요청: 마을·성이 너무 초라하다. 규모를 크게 늘리고 레퍼런스를 참조해 구조를 다시. 성은 훨씬 크게, 안에 시설과 일반 NPC, 왕족이 머무는 화려한 건물, 다양한 건물과 많은 오브젝트.
- 레퍼런스 조사(스타듀 펠리칸 타운, 젤다 하이랄 성 아래 마을, 옥토패스, 문라이터 라이노카, 코어키퍼, 중세 광장 도시·겹 성벽 성)
- 마을: 광장(우물·노점), 큰길·골목, 성문·성벽, 대장간·여관·상점가·신전·집·농장 구역
- 성(왕도): 바깥 마당과 본성의 겹 구조, 성문·다리, 병영·마구간·예배당·정원·분수, 왕족의 궁전(화려한 지붕·기둥·깃발·양탄자·왕좌)
- 사람들: 마을 사람·경비병·상인·귀족·아이(자리와 산책 길, 데이터)
- 오브젝트 많이(모두 서 있는 층, 생물군계마다 모습)
- **시안을 먼저 사람에게 보이고 확인받은 뒤 만든다**

### 2c. 바닥 아이템을 오브젝트로
사람 요청: 버섯 같은 것이 바닥에 떨어진 아이템이 아니라 오브젝트가 있고, 파괴하거나 수확하면 얻게.
- 버섯 무리·약초 덤불·광석 바위·조개 무더기 등(수확형과 부수기형), 다시 자람(게임 속 하루)

## 4. 크로스 플레이 준비 (PC·모바일·웹이 서로 멀티)

이미 모두 Unity Relay의 wss로 이어져 같은 방 코드로 만날 수 있는 구조다. 맞출 것:
- **지도 일치**(가장 중요): 참가자가 시드로 지도를 직접 만드는데 생성기에 실수 계산이 39줄 있어 기기·컴파일러마다 어긋날 수 있다 → 참가 때 지도 지문 비교, 다르면 호스트에게서 지도 받기(나중에 정수 계산으로)
- 통신 버전이 다를 때 "업데이트하세요" 안내와 버전 정책
- 웹 호스트는 탭을 숨기면 멈춘다 → 앱 호스트 권장·경고
- 휴대폰 백그라운드에서 끊긴 연결 다시 잇기
- Unity 대시보드에서 Relay 켜기(사람), iOS는 Mac 필요
