# 클래스와 스킬

M4에서 만든 클래스 조합 규칙과 시트 작성법이다. 코드는 `Assets/_Project/Scripts/Core/Simulation/ClassSheet.cs`, `World.Skills.cs`, 데이터는 `Assets/_Project/Data/Classes/`에 있다.

## 조합 방식

- **자유 조합**: 클래스 목록에서 아무거나 골라 섞는다. 지금은 최대 2개다(`HostConfig.MaxClasses`). 하나만 골라도 되고 안 골라도 된다(기본 공격만)
- 고르는 때: 메뉴에서 게임을 시작하기 전. 클래스 버튼을 누른 순서가 스킬 칸 순서다. 처음에는 전사와 화염 마법사가 둘 다 골라져 있다. 호스트는 모르는 클래스, 같은 클래스 두 번, 최대 개수를 넘는 것을 버리고 받아들인 목록을 돌려준다. 게임 중에 바꾸는 것은 아직 없다
- 고른 클래스마다 두 가지를 얻는다
  - **패시브**: 늘 붙어 있는 능력치. 장비 능력치와 같은 규칙(`Docs/Loot.md`의 계산식)으로 더해진다
  - **스킬**: 클래스마다 2개. 고른 순서대로 스킬 칸에 들어간다. 칸은 4개다(`ClassRules.SkillSlots`)
- 조합의 맛은 **태그**에서 나온다. 스킬과 공격에는 태그가 있고(근접, 마법, 화염 등), 태그가 붙은 능력치는 그 태그가 모두 있는 공격에만 적용된다. 그래서 한 클래스의 스킬이 다른 클래스의 패시브나 버프로 강해진다

## 클래스

처음 두 클래스(전사, 화염 마법사)에 궁수와 소환사를 더했다(2026-11-01).

| 클래스 | 패시브 | 스킬 |
|---|---|---|
| 전사 | 최대 생명력 20% 증가, 근접 피해 10% 증가 | 회전베기, 전투 함성 |
| 화염 마법사 | 화염 피해 15% 증가 | 화염구, 불꽃 부여 |
| 궁수 | 원거리 피해 15% 증가, 공격 속도 10% 증가 | 연발 사격, 매의 눈 |
| 소환사 | 소환수 피해 20% 증가, 최대 생명력 10% 증가 | 정령 부르기, 영혼 결속 |
| 폭풍술사 | 냉기 피해 10% 증가, 번개 피해 10% 증가 | 연쇄 번개, 서리 고리 |

| 스킬 | 태그 | 하는 일 |
|---|---|---|
| 회전베기 | 근접 | 둘레 1.8칸 안의 적을 모두 친다. 피해 150%. 재사용 4초 |
| 전투 함성 | (버프) | 6초 동안 근접 피해 30% 증가, 공격 속도 15% 증가. 재사용 15초 |
| 화염구 | 마법, 화염 | 겨눈 쪽으로 불덩이를 날린다. 적이나 벽에 닿으면 1.2칸 안을 터뜨린다. 피해 120%. 재사용 1.5초 |
| 불꽃 부여 | 화염 (버프) | 8초 동안 기본 공격과 모든 스킬에 화염 태그가 붙는다. 재사용 16초 |
| 연발 사격 | 원거리 | 겨눈 쪽을 가운데로 12°씩 벌어진 화살 5발을 쏜다. 한 발마다 처음 닿은 적 하나를 친다. 피해 70%, 사거리 9칸, 재사용 4초 |
| 매의 눈 | 원거리 (버프) | 6초 동안 원거리 피해 25% 증가, 치명타 확률 +8. 재사용 14초 |
| 정령 부르기 | 소환, 마법 | 정령 2마리가 15초 동안 곁에서 싸운다. 0.8초마다 한 번, 피해 40%. 재사용 18초 |
| 영혼 결속 | 소환 (버프) | 8초 동안 소환수 피해 40% 증가. 재사용 16초 |
| 연쇄 번개 | 마법, 번개 | 겨눈 쪽으로 번개를 쏜다. 맞은 적에게서 둘레 3.5칸 안의 적 둘에게 절반씩 튄다. 피해 110%, 재사용 2초 |
| 서리 고리 | 마법, 냉기 | 둘레 2.2칸을 얼려 친다. 맞은 적은 2초 동안 느려진다. 피해 130%, 재사용 6초 |

피해 %는 그 스킬의 태그로 계산한 내 피해에 곱한다. 무기의 고정 피해(`Damage+4~6`)는 태그가 없어서 모든 공격에 들어가고, 지팡이의 `Magic:Damage+10%`는 마법 태그가 있는 화염구에만 들어간다.

**조합 예**: 전사 + 화염 마법사가 불꽃 부여를 켜고 회전베기를 쓰면, 회전베기가 근접과 화염 태그를 함께 가진다. 전사 패시브(근접 피해), 전투 함성(근접 피해), 화염 마법사 패시브(화염 피해), 장비의 `불타는`(화염 피해)과 `투사의`(근접 피해) 접사가 모두 붙는다. 소환사 + 화염 마법사도 같다: 불꽃 부여를 켜면 정령의 공격도 화염이 되어 화염 마법사 패시브가 붙는다. 궁수는 활을 들면 기본 공격에도 원거리 패시브와 매의 눈이 붙는다.

## 원소 피해

`Docs/Loot.md`에서 미뤄 둔 규칙이다.

- 원소는 태그로만 다룬다. 화염 태그가 있는 공격의 피해가 화염 피해이고, `Fire:Damage+N%`가 그 공격을 키운다
- 원소 피해를 더하는(무기에 화염 피해 +N을 붙이는) 방식은 아직 없다. 불꽃 부여처럼 태그를 주는 효과가 그 자리를 맡는다
- 원소마다 효과와 몬스터의 저항이 있다(2026-11-01). `Docs/Combat.md`의 "원소"

## 스킬 규칙

- **쓰기**: PC는 Q, E, R, F(화면 아래 가운데에 칸이 보인다. 메뉴의 [키 바꾸기]에서 바꿀 수 있다). 휴대폰은 오른쪽 아래 구석의 스킬 버튼 4개(2×2). 마우스 쪽으로 쓰고, 휴대폰은 공격 스틱을 잡고 있으면 그 쪽, 아니면 바라보는 쪽으로 쓴다. 버튼은 다른 손가락이 스틱을 잡고 있어도 눌린다
- **화면**: 칸마다 재사용 대기가 어둡게 덮이고 남은 초가 나온다. 버프가 걸린 칸은 테두리가 빛나고, 걸린 사람 둘레에 버프 색 고리가 생긴다. 스킬은 태그 색(화염 주황, 마법 보라, 근접 은색)으로 그려서 불꽃 부여를 켠 회전베기는 주황으로 보인다. 가방 창에 클래스와 스킬별 지금 피해가 나온다
- **재사용 대기**: 스킬마다 따로 돈다. 호스트가 정하고 스냅숏으로 알려 준다. 마나 같은 자원은 아직 없다
- **버프**: 같은 버프를 다시 쓰면 지속 시간만 처음으로 돌아간다. 쓰러지면 버프가 모두 사라진다. 버프의 능력치는 장비·패시브와 같은 식으로 더해진다
- **피해와 치명타**: 스킬은 쓸 때(화염구는 쏠 때) 그 태그로 계산한 피해와 치명타를 한 번 정하고, 맞은 적 모두에게 그 피해를 준다. 방어도는 적마다 따로 뺀다. 기본 공격은 지금처럼 맞은 적마다 치명타를 정한다
- **화염구**: 플레이어 투사체는 적과 보스에만 맞고 다른 플레이어는 통과한다. 사거리 10칸을 날면 그 자리에서 터진다
- **연발 사격**: 화살마다 따로 날지만 피해와 치명타는 쏠 때 한 번 정한다. 큰 적(보스)에게 가까이서 쏘면 여러 발이 함께 맞는다
- **정령(소환수)**
  - 부르면 플레이어 둘레에 나타나, 플레이어에게서 7칸(`range`) 안의 가장 가까운 적이나 깨어 있는 보스에게 날아가 친다. 잠든 보스는 건드리지 않아서 정령이 보스를 깨우지 않는다. 칠 적이 없으면 플레이어 곁 제자리(둘레에 고르게)로 돌아오고, 4칸 넘게 떨어지면 빨리 따라온다
  - 정령은 벽을 지나 날아다니고, 아무것도 정령을 해치지 못한다. 대신 시간이 지나거나(`duration`) 플레이어가 쓰러지거나 나가면 사라진다. 다시 부르면 그 칸의 옛 정령은 사라지고 새로 나온다(지금은 재사용 18초가 15초보다 길어서 겹치지 않는다)
  - 피해는 칠 때마다 그 순간의 플레이어 능력치로 정한다(스킬의 태그와 버프가 주는 태그로 계산한 피해 × `damage`%, 치명타도 그때). 그래서 정령이 나와 있는 동안 버프를 켜도 바로 세진다. 맞힌 피해와 처치(떨어뜨리는 것)는 플레이어 것이다. 정령은 적을 밀쳐내지 않는다(자주 쳐서 적이 다가오지 못하게 된다)
  - 화면: 스킬 태그 색(소환은 청록)의 작은 유령. 어둠 속에서 은은하게 빛나고, 사라지기 2초 전부터 깜빡인다. 다른 사람의 정령도 보인다(엔티티 종류 `Minion`)

## skills.csv

`Assets/_Project/Data/Classes/skills.csv`. 한 줄이 스킬 하나이고, 같은 클래스의 스킬은 적힌 순서대로 칸에 들어간다.

| 열 | 내용 |
|---|---|
| id, name | id와 화면 이름 |
| class | 이 스킬을 주는 클래스의 id |
| kind | `nova`(내 둘레), `projectile`(겨눈 쪽으로 날아감), `buff`(나에게 걸림), `summon`(소환수를 부름) |
| tags | 스킬의 태그. `melee`, `magic`, `fire` 등을 `\|`로 |
| damage | 피해 %. `nova`, `projectile`, `summon`(소환수가 한 번 칠 때)에 필요하다 |
| cooldown | 재사용 대기(초) |
| radius | `nova`의 범위, `projectile`이 터지는 범위(칸). 0이면 맞은 하나만 친다 |
| speed, range | `projectile`의 초당 속도와 최대 거리(칸). `summon`은 소환수의 초당 속도와, 플레이어에게서 몇 칸 안의 적을 칠지 |
| duration | `buff`의 지속 시간, `summon`의 소환수가 머무는 시간(초) |
| count | `projectile`이 한 번에 쏘는 개수(12°씩 부채꼴), `summon`이 부르는 소환수 수. 비우면 1, 많아야 8. 이 열이 없는 옛 시트도 읽는다 |
| modifiers | `buff`가 거는 능력치 |
| grants | `buff`가 내 공격에 붙여 주는 태그 |
| description | 화면에 보이는 설명 |

모양마다 필요한 열이 비어 있으면 테스트가 `skills.csv 3행: projectile 스킬은 speed 칸을 채워야 합니다`처럼 알려준다.

## 2개보다 많이 고르게 할 때 (점검)

나중에 3개 이상을 고르게 바꿀 수 있는지 미리 확인했다. 데이터와 통신은 그대로 두고 아래만 고치면 된다.

- **그대로 되는 것**
  - 고른 클래스는 처음부터 목록으로 다룬다. 참가 메시지, 호스트가 받아들인 목록, 플레이어 상태가 모두 개수 제한 없는 목록이고, 최대 개수는 `HostConfig.MaxClasses` 하나다
  - 패시브는 고른 클래스 수만큼 그냥 더해지고, 스킬 명령은 칸 번호로 오가므로 칸 수가 바뀌어도 메시지 모양은 같다
  - 메뉴의 클래스 고르기는 시트에 있는 클래스를 모두 보여 주고 최대 개수까지 고르게 한다
- **고쳐야 하는 것**
  - **스킬 칸 고르기**: 클래스 2개 × 스킬 2개 = 칸 4개라서 지금은 자동으로 채운다. 클래스가 늘면 스킬이 칸보다 많아지므로 어떤 스킬을 어느 칸에 둘지 고르는 창과 호스트 명령(`AssignSkill`)이 필요하다. 칸 수를 늘리는 대신 고르게 하는 쪽을 권한다. 휴대폰 화면에 버튼을 무한정 늘릴 수 없다
  - **패시브 균형**: 패시브가 그대로 쌓이면 클래스를 많이 고를수록 세진다. 3개 이상을 열 때는 클래스 수에 따라 패시브를 나누거나(예: 1/N), 클래스마다 레벨을 두고 포인트를 나눠 쓰게 하는 것 중 하나를 정해야 한다
  - **화면**: PC의 스킬 막대(Q, E, R, F)는 칸 4개 기준이다. 휴대폰 버튼은 두 개씩 줄을 늘려 가지만, 세 줄부터는 화면을 가린다
- 결론: 2개로 시작해도 나중에 늘릴 때 버릴 코드는 없다. 늘릴 때 정할 것은 위 두 가지(스킬 칸 고르기, 패시브 균형)다

## 조정하는 법

`dotnet run --project DevTools/CoreSandbox -- --fight 120 42 --classes warrior,fire_mage`처럼 클래스를 주면 봇이 스킬을 준비되는 대로 쓰면서 싸운다(회전베기는 둘레에 적이 있을 때, 화염구는 사거리 안에 적이 있을 때, 버프는 싸우는 중에). 보스는 `--boss 300 42 --classes warrior,fire_mage`. 결과에 준 피해가 기본 공격과 스킬별로 나뉘어 나온다.

| 클래스 | 혼자 보스 처치 | 슬라임 사냥(시드 42, 분당 처치) |
|---|---|---|
| 없음 | 82~133초, 다섯 번 중 두 번은 못 잡음 | 11 |
| 전사 | 54~79초 | 14.5 |

| 궁수 | 54~74초 | (활) 초당 피해 7.7 |

- 궁수·소환사(2026-11-01, 시드 1~3): 혼자 보스는 전사·화염 마법사와 같은 50~70초에 들게 맞췄다. 처음 숫자(연발 사격 60%, 정령 45%)에서 소환사 + 화염 마법사가 전사 + 화염 마법사보다 빨라서 정령을 40%로 내리고, 봇이 거의 맞히지 못하는 연발 사격은 70%로 올렸다. 슬라임 사냥은 아무 클래스 없이 초당 6.6, 전사 9.1이다. 활을 든 궁수 봇은 보스의 돌진에 자주 쓰러진다(아래 무기별과 같은 까닭)

- 2명은 75~86초에서 33~40초로, 4명은 68~85초에서 32~37초로 줄었다(시드 1~3)
- 처음 숫자(화염구 140%, 재사용 1.2초)에서는 화염 마법사 혼자가 전사보다 한참 빨라서 120%, 1.5초로 낮췄다
- 무기별(전사 + 화염 마법사, 시드 1~5): 검 38~55초, 활 43~125초, 지팡이 42~131초. 원거리 봇은 거리를 서툴게 유지하고, 보스의 돌진은 가장 먼 사람을 노려서 사람이 할 때보다 불리하게 나온다. 활·지팡이의 손맛은 직접 해 보고 맞춘다
- 두 클래스를 고르면 보스가 두 배 넘게 빨리 죽는다. 보스가 너무 쉽게 느껴지면 스킬보다 `bosses.csv`의 체력을 먼저 올린다. 이제는 거의 모두가 클래스를 고를 것이기 때문이다
