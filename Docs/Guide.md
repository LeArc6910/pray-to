# 목표 안내

처음 하는 사람이 길을 잃지 않게, HUD에 다음에 할 일을 하나씩 보여 준다(2026-11-01). 코드는 `Assets/_Project/Scripts/Core/Guide/GuideSheet.cs`(시트, 조건, 진행)와 `Scripts/Client/GameRoot.cs`(보여 주기), 데이터는 `Assets/_Project/Data/Guide/goals.csv`에 있다.

## 보이는 것

- HUD에 "목표 3/11: 횃불 세우기"처럼 지금 목표가 나오고, 목표가 바뀐 뒤 30초 동안은 그 아래에 하는 법(힌트)이 나온다. 가로로 든 휴대폰처럼 낮은 화면에서는 힌트를 빼고, 가방을 열면 HUD가 줄어 목표도 숨는다
- 목표를 이루면 왼쪽 아래에 "목표 달성: …"이 뜨고 소리가 난다. 다 마치면 "안내한 목표를 모두 마쳤습니다"가 뜨고 HUD에서 사라진다

## 규칙

- 목표는 순서대로다. 반 초마다 지금 목표를 확인하고, 이미 이룬 목표는 한꺼번에 지나간다. 그래서 불러온 캐릭터는 해 둔 만큼 건너뛴다
- 한 번 지난 목표는 되돌아오지 않는다. 돌을 작업대에 써서 10개 아래로 줄어도 "돌 10개 모으기"는 끝난 채다
- 어디까지 왔는지는 캐릭터 이름마다 이 기기에 남긴다(PlayerPrefs `guide.<이름>`). 게임의 저장본에는 넣지 않는다. 안내는 화면만의 일이라 협동에서 남의 진행에 영향이 없다
- 협동에서 "세우기" 목표는 누가 세웠든 월드에 그 물건이 있으면 이룬 것으로 친다

## goals.csv

한 줄이 목표 하나이고, 줄 순서가 목표 순서다.

| 열 | 내용 |
|---|---|
| id | 영문 id |
| text | HUD에 나오는 할 일 |
| hint | 하는 법. 쉼표는 쓰지 않는다(CSV) |
| done | 이룬 것으로 칠 조건. `\|`로 여럿을 적으면 그중 하나만 맞으면 된다 |

조건:

| 조건 | 뜻 |
|---|---|
| `have:<id>` | 그 재료·소모품·아이템을 하나 이상 가졌다(아이템은 가방과 착용을 함께 센다) |
| `have:<id>:<개수>` | 그만큼 가졌다 |
| `place:<칸 종류>` | 월드에 그 칸이 있다(`Workbench`, `Torch` 같은 `TileType` 이름) |
| `plant` | 무언가 자라고 있다 |
| `reach:<타일 수>` | 시작 지점에서 그만큼 떨어진 곳에 와 있다 |

시트의 id나 칸 종류가 틀리면 메뉴에 "데이터 시트 오류"로 줄 번호와 함께 나온다.
