# 이펙트 개편: 점검과 개선안 (2026-11-27)

사람 요청: "범위 공격이나 투사체 등의 이펙트가 너무 단순하게 그려지는 것 같아. 디테일을 보강하고 싶어. 유저가 사용하는 스킬부터, 몬스터, 보스까지 전부 점검 후 개선안 보여주면 체크해볼게". 이 문서는 **점검과 시안까지**다. 게임 코드는 바꾸지 않았고, 사람이 고른 뒤 다음 요청으로 적용한다.

"지금"은 스킬·일반 몬스터는 게임 코드(`SkillFx`, `MonsterFx`) 그대로, 보스는 `WorldView`가 하는 일을 미리보기에 옮겨 그린 것이다. "개선안"은 미리보기 안에서만 그린다(`FxMockKit.cs`, `FxMockPreview.cs`).

## 3. 개선안

모든 이펙트를 **다섯 층**으로 쌓는다: ①바닥 흔적(그을음·균열·서리, 정렬 20) ②바닥 빛(원소색, 세 띠로 끊어 더한다) ③몸통(원소 모양, 5색 램프) ④가장자리(판정 크기의 테·충격파 고리) ⑤입자(꼬리 달린 불티·파편·연기). 지금은 ③④와 입자 조금뿐이다.

| 종류 | 지금 | 바꿀 것 | 시안 |
|---|---|---|---|
| 예고(위험 영역) | 빨강 반투명 도형 | 2px 테(밝은 선 + 어두운 선)는 처음부터 끝까지, 속은 아주 옅게(0.14), 차오르는 부분은 줄무늬 + 앞선 밝은 줄, 마지막 14%는 통째로 깜빡임. 빨강(위험)·노랑(돌진)·금(모이기) 약속은 그대로. 예고 위에는 연기·먼지를 그리지 않는다 | b1~b5, m2~m4 |
| 범위 공격(착지) | 주황 원형 폭발 하나 | 예고와 **같은 모양**으로 터진다(부채꼴은 칼자국이 쓸고 지나감, 고리는 띠를 따라 불이 돎). 흰 번쩍임 1프레임(0.05초) → 원소 몸통 → 충격파 고리 → 입자 → 바닥 흔적 0.9~1.6초 | b1 b2 b3, s2 s3 |
| 투사체 | 4~9px 한 장 | 어두운 테 + 색 껍질 + 밝은 핵, 2프레임 맥동, 줄어드는 꼬리 3~6마디, 바닥 빛, 사라질 때 고리와 파편. 적의 탄은 원소가 무엇이든 **붉은 테**를 두른다. 쏘기 전 조준선(점선) | s1 m1 b6 |
| 장판 | 테두리 원, 불꽃 몇 개 | 어두운 가장자리 + 밝은 속의 울퉁불퉁한 웅덩이, 거품·불티, 바닥 빛, **위험한 동안 붉은 점선 테** | m2 m4 |
| 폭발 | 핵 + 테, 6프레임 | 흰 핵 → 노랑 → 주황 → 빨강 덩어리(일렁이는 가장자리)가 0.2초에 부풀고 속부터 연기로 비워진다. 고리, 감속하는 불티 10~16, 튀는 돌, 오르는 연기 5, 그을음 | s1 s5 |
| 원소 | 4색 램프, 스킬·몬스터만 모양 | 5색 램프(어두울수록 색상이 돈다). 불=일렁이는 혀·불티·연기, 얼음=각진 결정이 서고 깨짐·서리 바닥, 번개=꺾인 선(0.04초마다 새로)·후광·그을린 점, 독·포자=웅덩이·거품·오르는 알갱이, 결정=가시·깨지는 조각·분홍 빛, 흙=먼지 구름·균열·돌. **보스에도 같은 표를 쓴다** | 전부 |
| 근접 | 얇은 호 | 머리가 굵고 흰 스미어가 뒤로 가늘어진다(끝은 점점이), 가장자리 먼지, 맞은 곳의 별과 불티 | s4 b3 |
| 필살기 | 보통 공격과 같은 리듬 | 방을 25% 어둡게 해 빛이 돋게, 떨어지는 것의 그림자와 본체, 착지 뒤 0.5초 서 있다가 깨짐, 화면 번쩍임은 1프레임만 | s5 b5 |

**읽기 쉬움을 지키는 약속**: 테는 실제 판정 크기 그대로. 플레이어 이펙트는 테두리와 원소색, 적의 위험은 채운 빨강 + 굵은 테로 계속 구분. 흑백으로 바꿔도 예고가 읽혀야 한다(적용할 때 `_gray` 표를 함께 뽑는다). 남의 이펙트는 지금처럼 0.6배.

**성능 한도**(휴대폰·웹): 이펙트 하나 72조각, 화면 420조각, 동시 48개는 그대로 둔다. 새로 더하는 것: 바닥 빛은 이펙트당 3장·화면 12장까지(큰 반투명이라 가장 비싸다), 바닥 흔적은 화면 24개·1.6초까지, 방 어둡게·화면 번쩍임은 필살기와 큰 착지에만. 시안의 조각 수(`report.txt`)는 대부분 21~68이고 **유성 84, 불의 고리 90, 결정 비 81은 한도를 넘는다** — 적용할 때 불꽃 줄을 한 장의 프레임 그림으로 굽거나 수를 줄여야 한다. 조각 수는 미리보기의 그리기 호출을 센 어림이다.

## 4. 적용할 때의 묶음과 규모

| 묶음 | 내용 | 규모 | 비고 |
|---|---|---|---|
| E1 | 보스 예고 도형과 공용 착지(모양에 맞는 타격, 재질별 파편) | 중 | 효과가 가장 크다. 고유 코드 없는 네 보스도 함께 나아진다 |
| E2 | 보스 투사체(원소별 탄, 꼬리, 소멸, 조준선) | 소 | |
| E3 | 공용 층 조각(바닥 빛, 그을음·균열, 연기, 꼬리 불티)과 폭발 | 중 | E4~E6의 바탕 |
| E4 | 플레이어 스킬 30종에 층 더하기 | 대 | 클래스마다 나눠서 |
| E5 | 일반 몬스터 예고(굵은 테, 차오름)·탄·장판 | 중 | |
| E6 | 보스 고유(여왕 광선·결정 비, 모르그 불, 그 밖) | 대 | 보스 작업 세션들이 끝난 뒤 |
| E7 | 원소별 타격 모양, 피해 숫자 | 소 | |

권하는 차례: E1 → E2 → E3 → E5 → E4 → E6 → E7.

**정해야 할 것**: (1) 바닥 빛을 더하는 방식 — 가산 혼합 재질은 셰이더를 빌드에 넣어야 해서 로컬 작업이 생긴다. 옅은 보통 혼합 그림으로 흉내 내거나 이미 있는 빛 지도(`LightMap`)에 광원으로 넣는 길도 있다. (2) 예고를 픽셀 그림으로 바꾸면 크기마다 그림이 필요하다(지금은 한 장을 늘린다). (3) 방을 어둡게 하는 연출을 플레이어 스킬에도 쓸지(시안의 천둥은 쓴다).

## 5. 시안에서 직접 판단한 것

- 포자 주머니는 몬스터의 색(보라)을 지켰다. 독 초록 램프는 표에만 있다.
- 유성은 지금 땅을 따라 날아가지만 시안은 위에서 떨어진다(판정 위치와 시간은 같다, 그림만).
- 보스 장면의 원·고리·부채꼴·광선 크기와 시간은 대표값이다(특정 공격의 시트 값이 아니다).
