# 무기 점검 (2026-11-28)

사람 요청: "지금 시험장 기준으로 공허검이 타격음도 없고 앞에 베는 모션도 없는데 이 무기만 그런건지 다른 무기도 그런건지 전체적으로 점검 한번 해줘."

## 원인

공허검만의 일이 아니었다. `Client/WeaponFeel.cs`(무기 종류마다의 느낌, `396ec37`)는 구조체인데, 검의 느낌을 `new WeaponFeel()`로 만들었다. C# 9에서 구조체의 `new T()`는 기본값 매개변수가 있는 생성자를 부르지 않고 **모든 값이 0인 기본값**을 만든다. 그래서 검 느낌을 쓰는 모든 것에서 호 크기·소리 크기·내딛기·밀림·멈춤·흔들림이 0이었다.

- 베는 호: 크기 0배라 보이지 않음
- 휘두르기·맞힘 소리: 음량 0이라 `Sounds.Play`가 아예 내지 않음(활·지팡이의 쏘기 소리도)
- 내딛기·밀림·타격 멈춤도 없음

검 느낌을 쓰는 것: 검·활·지팡이·곡괭이 동작의 무기, 맨손, 그리고 **몬스터의 휘두르기와 몬스터가 다른 플레이어를 칠 때**. 고유 느낌이 있는 새 8종(단검·대검·창·망치·석궁·부메랑·완드·오브)은 멀쩡했다.

## 고친 것

- `WeaponFeel.Sword = new WeaponFeel(volume: 1)`: 생성자를 거쳐 기본값 1이 들어간다
- 휘두르기·맞힘 소리 고르기를 `WeaponFeel.SwingSound`·`HitSound`로 빼서 화면과 점검이 같은 것을 쓴다
