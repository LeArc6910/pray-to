# 보스 패턴 재설계 기획안 (2026-11-28)

사람 요청(2026-11-28): "보스들 패턴이 너무 획일화된 것 같다. 아라크네(아라네)나 시구레 정도가 그나마 개성적이고 나머지는 직선, X자, 원형, 투사체만 반복한다. 각 몬스터 컨셉에 맞게 패턴을 재설계하고, 페이즈가 넘어가면 확 어려워짐을 체감하게 전체 패턴 속도를 빠르게, 또는 기본 패턴이 강화되어 나오게(예: 시구레 3연속 대시베기 → 더 빠른 5연속, 용암 거인은 맵에 용암을 깔아 일정 시간 동선 방해)."

**기획안만이다.** 코드·시트는 바꾸지 않았다. 사람이 아래 표에서 고르고 고친 뒤 묶음(5절)대로 만든다. 수치는 시안이고 만들 때 `--hits`와 봇으로 다시 잰다.

## 2. 원칙

### 2.1 보스마다 고유 메커니즘

1. **컨셉에서 나오는 규칙 하나 이상**: 그 보스에서만 배우는 피하는 법(용암 = 바닥이 좁아짐, 물 = 밀려남·잠수, 망령 = 진짜 찾기, 공허 = 끌려감). 이름만 다른 "원·직선"은 뺀다
2. **같은 모양이라도 맥락이 다르다**: 원이라도 "남아서 길을 막는 원", "기둥 뒤에 숨는 원", "진짜 분신만 쏘는 직선"처럼 발동 조건·연계·지형이 다르게
3. **1페이즈는 그대로 단순하게**(`Docs/Bosses.md` 페이즈 배치의 규칙 유지): 기본기 셋~넷 + 고유 메커니즘의 맛보기 하나
4. **한 번에 두 겹까지**(그대로): 지형이 남아 있는 것은 겹으로 세지 않되, 지형 위에 새 예고는 한 겹만 더 얹는다

### 2.2 페이즈가 넘어가면 확 어려워짐

| 수단 | 1페이즈 | 2페이즈 | 3페이즈 | 비고 |
|---|---|---|---|---|
| **예고 시간** (새로) | ×1 | ×0.85 | ×0.75 | 바닥: 보통 0.5초, 필살기 1.2초, 연속의 둘째부터 0.3초 |
| **쉼** (지금 0.85·0.7) | ×1 | ×0.75 | ×0.6 | 빈틈(발두인 망치 박힘 등)은 줄이지 않는다 |
| **이동** | ×1 | ×1.1 | ×1.2 | 돌진·탄 속도 포함 |
| **강화판** | 기본 | 수·연속·범위 +1단 | +2단, 마지막 타가 더 크게 | 같은 이름, 같은 몸짓, 더 많이·빨리(아래 보스 표의 "2·3 강화") |
| **지형** | 맛보기 | 남는 시간 늘고 더 자주 | 아레나 자체가 바뀜(좁아짐·물·용암) | 5절 공용 틀 T3·T6 |
| **연계** | 없음 | 둘 잇기 | 셋 잇기 | 공용 틀 T2 |

- 피해 몫은 **1페이즈 예고 길이로 정한 구분을 그대로** 쓴다(`Docs/Difficulty.md`). 예고가 짧아져도 한 방은 같고, 늘어난 수만큼 연속 몫(한 번 20~30%)으로 나눠 다 맞아도 죽지 않게 한다. 필살기만 89~95%
- **공정함**: 강화판은 1페이즈에서 본 몸짓과 같아서 읽을 수 있다. 연속 공격은 사이 간격이 구르기 재사용보다 길다(시험으로 지킨다). 새 지형은 처음 나올 때 한 번은 피해가 없이 깔린다(보고 배우게)
- **전환 연출(공용)**: 포효(지금) + 1.5초 무적 + 아레나 변화 한 가지(용암이 차오름, 물이 들어옴, 꽃잎 결계 등) + 그 페이즈 첫 공격은 강화판 하나(지금 `OpensPhase`를 강화판까지 넓힌다) + 음악 템포 한 단(지금처럼)

## 3. 보스마다 기획

표 읽는 법: **남김**(지금 공격 유지, 강화만 더함), **바꿈**(이름·몸짓은 살리고 규칙을 바꿈), **새로**, **뺌**. 모양은 지금 엔진 말(`circle`·`trail` 등) 또는 5절 공용 틀(T1~T8). "2·3 강화"는 1페이즈에서 본 공격이 그 페이즈에서 어떻게 커지는지.

### 3.1 동굴 수호자 — 돌기둥과 핵 (첫 보스, 가르치는 보스)

- **컨셉**: 마왕군 문양이 새겨진 핵으로 움직이는 바위 골렘(이야기 2장 "깨어난 수호자")
- **고유 메커니즘**: **바위 기둥**(T3 장애물). 낙석·지진이 아레나에 기둥을 세운다. 기둥은 탄을 막는 엄폐물이고, **돌진이 기둥에 박히면 수호자가 2초 기절**(핵이 드러나 더 아프게 맞는다). 첫 보스라 "지형을 이용한다"를 가르친다
- **전환**: 2페이즈 핵에 금이 가 빛이 샌다 + 기둥 둘이 솟는다. 3페이즈 천장이 흔들려 돌가루가 계속 떨어진다. 템포는 첫 보스라 한 단 약하게(예고 ×0.9·×0.8)

### 3.2 개미귀신 — 끌려드는 모래

- **고유 메커니즘**: **개미지옥 끌림**(T4 끌어당김) + **모래 속 이동**(T5 숨기). 구덩이는 가운데로 천천히 끌고(걸음의 30%), 가운데에서 턱이 문다. 땅속에선 **모래 둔덕**이 보여 어디로 오는지 읽는다
- **전환**: 2페이즈 아레나 가운데가 꺼져 큰 개미지옥(반지름 3칸)이 늘 남는다. 3페이즈 둘레에 작은 구덩이 셋이 더 생긴다

### 3.3 수정 거미 여왕 — 빛을 꺾는 수정

- **컨셉**: 수정 동굴의 왕관 쓴 거미. 왕관의 빛과 알(3장 "흩어진 힘")
- **고유 메커니즘**: **수정 기둥과 빛 꺾기**(T3 장애물 + 반사). 여왕이 수정을 꽂고, 왕관의 빛(광선)이 수정에 닿으면 **꺾여** 다른 쪽으로 간다. 수정은 때려서 부술 수 있다(부수면 파편 둘레 피해). 아라네의 거미줄(밟는 바닥)과 달리 "서 있는 기둥이 길을 만든다"
- **전환**: 2페이즈 수정 셋이 둘레에 솟는다. 3페이즈 수정끼리 **빛의 실**로 이어진다(넘으면 아프다, 수정을 부수면 끊긴다)

### 3.10 벚꽃 검귀 시구레 — 남기고 강화만 (사람이 자세히 지시해 만든 보스)

- **새 메커니즘 하나**: **납도 반격**(2페이즈부터, T2 조건): 칼을 칼집에 넣은 채 눈을 감고 서 있는 자세(1.5초, 꽃잎이 멈춘다). 이때 때리면 반격 일섬(필살 몫)이 온다 → **때리지 말고 기다리거나 멀어진다**. 자세가 끝나면 빈틈 1초. 읽는 단서: 칼자루의 빛이 꺼지고 꽃잎이 공중에 멈춤
- **전환**: 3페이즈 **벚꽃 결계**: 아레나 가장자리에 꽃잎 벽이 서서 반지름 10 → 7.5(닿으면 밀려남, 피해 작게). 납도 자세가 더 길게(눈을 뜬다)

| 공격 | 페이즈 | 2 강화 | 3 강화 |
|---|---|---|---|
| 거합 베기 | 전부 | 예고 0.9 → 0.75 | 뽑아 베기 + 되베기 2연 |
| 일섬 | 전부 | 끝에서 되돌아오는 둘째 일섬(0.4초) | 왕복 후 잔월 고리 |
| 십자 베기 | 전부 | 베인 자리에 잔월 선 1초 | 별(대각 더) |
| **삼연 발도** | 2~3 | 둘째부터 0.45 → 0.35초 | **오연 발도**: 다섯 번, 첫 예고 0.7초, 둘째부터 0.3초, 돌진 초속 40 → 48, 한 번 몫 20%(사람 예시) |
| 월광참 | 2~3 | 다섯 발 | 일곱 발 두 물결(엇갈림) |
| 회전 발도 | 2~3 | — | 두 바퀴(둘째가 반지름 4.5) |
| 납도 반격 | 2~3 | **새로** 1.5초 | 2.0초, 반격이 사방 일섬 셋 |
| 벚꽃 난무 | 3 | — | 사람마다 넷 → 여섯 |
| 순보 일섬 | 3 | — | 2연 → 3연 |
| 오의 천섬(필살) | 3 | — | 그대로(결계로 좁아진 곳에서) |

### 3.11 흑철 기사 발두인 — 남기고 강화만 (사람이 자세히 지시해 만든 보스)

- **컨셉 그대로**(느린 한 방). 강화는 "느린데 끝나지 않는다": 연타가 붙는다. 빈틈(망치 박힘)은 줄이지 않는다
- **새 메커니즘 하나**: **균열 줄**(T3 장판): 망치가 박힌 자리에서 균열이 남고(8초), 충격파·대지 강타가 **균열을 따라 다시 달린다**. 균열 위에 서지 않는 것이 요령
- **전환**: 3페이즈 **투구를 벗어 던진다**(쿵): 걸음 2.0 → 2.6, 예고 ×0.8(공용 ×0.75보다 약하게, 무거운 보스라), 숨이 거칠어지고 망치에 붉은 열

| 공격 | 페이즈 | 2 강화 | 3 강화 |
|---|---|---|---|
| 망치 내려찍기 | 전부 | 내려찍은 뒤 끌어올리며 올려치기(cone 60°, 0.6초) | 3연, 마지막에 균열 + 충격파 |
| 휩쓸어 치기 | 전부 | — | 왕복 |
| 어깨 돌진 | 전부 | 2연(꺾기) | 끝에 내려찍기 |
| 대지 강타 | 2~3 | 균열을 따라 원이 터짐 | 두 번(1.0초 차) |
| 충격파 | 2~3 | 균열을 따라 달림 | 세 갈래 |
| 도약 내려찍기(필살) | 2~3 | 그대로 | 2연 도약(둘째 예고 1.2초) |
| 십자 균열 | 3 | — | 균열로 남음 |
| 무너지는 천장 | 3 | — | 그대로 |
| 심판의 일격(필살) | 3 | — | 그대로 |

### 5.2 묶음과 순서 제안

| 묶음 | 내용 | 그림·소리 (Fable 하위 작업) |

- 대략: R1 한 세션, R2·R3 각 한두 세션, R4 두 세션
