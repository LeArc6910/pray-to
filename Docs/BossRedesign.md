"피하는 법"으로 나눴다. 지금 우리 보스가 쓰는 것은 ① 하나다(아라네만 ②, 그룸·발두인·아라네가 ④ 조금).

|---|---|---|---|---|
| ① | 예고된 곳 피하기 | 나간다 | 모두 | 있음 |
| ② | **바닥 남기기** | 남은 장판을 돌아간다, 식으면 밟는다 | 코어키퍼 이그니우스, 하데스 | `pool` 넓힘 |

## 4. 원칙

### 4.1 계열 나누기

1. 보스마다 ① 말고 **계열 둘~셋**. 그 보스의 첫 계열은 컨셉에서 나온다(용암 = ②, 공허 = ⑤)
2. **한 계열은 세 보스까지**(아래 표가 지킨다). 같은 계열이라도 맥락이 다르다(②: 용암은 식어서 발판, 망령의 웅덩이는 번개가 퍼짐, 아라네의 거미줄은 묶음)
3. **처음 만나는 순서대로 쉬운 계열부터**: 수호자(⑧·③ 기둥)·개미귀신(⑤·④)이 가르치고, 뒤 보스가 섞는다

### 4.2 페이즈가 넘어가면 확 어려워짐

| 수단 | 1페이즈 | 2페이즈 | 3페이즈 | 출처 |
|---|---|---|---|---|
| **예고 시간**(새로) | ×1 | ×0.85 | ×0.75 | 컵헤드(예고 길이가 어려움) |
| **쉼**(지금 0.85·0.7) | ×1 | ×0.75 | ×0.6 | 실크송 레이스(기술 전부가 빨라짐) |
| **이동·탄 속도** | ×1 | ×1.1 | ×1.2 | 피시론 공작(빠르게 돌림) |
| **연타 +1**(강화판) | 기본 | +1 | +2, 마지막 타가 더 크게 | 몬스터 헌터 분노(3 → 4), 데드 셀(찌르기 → 연타) |
| **새 요소 하나** | 계열 맛보기 | 계열 하나 본격 | 계열 둘 겹침 + 아레나 위협 | 하데스 극한 조치, 레이스 |
| **막간**(셋만) | | | 2→3 전환에 10~15초 | 데드 셀, 미스릭스, WoW |

- 바닥: 보통 예고 0.5초, 필살기 1.2초, 연타의 둘째부터 0.3초. 연타 사이는 구르기 재사용보다 길게(시험)
- 피해 몫은 **1페이즈 예고 길이로 정한 구분 그대로**(`Docs/Difficulty.md`). 늘어난 연타는 연속 몫(한 번 20~30%)으로 나눠 다 맞아도 죽지 않게. 필살기만 89~95%
- **처음 나오는 새 계열은 한 번은 피해가 없이** 깔리거나 느리게 나온다(앞에서 배운 것을 되짚고 새것을 더한다)
- **필살기에 이름**: 동방 스펠 카드처럼 필살기를 쓸 때 화면 위에 이름이 잠깐 뜬다(로스트아크도 패턴에 이름). 이름이 피하는 법을 비춘다(예: "식은 바위 위로")
- **전환 연출(공용)**: 포효 + 1.5초 무적 + 아레나 변화 하나 + 그 페이즈 첫 공격은 새 계열의 강화판 + 음악 템포 한 단(지금처럼)

## 5. 보스마다 기획

표 읽는 법: **계열**은 3절 번호. **남김**(지금 공격 유지, 강화만), **바꿈**(이름·몸짓은 살리고 규칙을 바꿈), **새로**. 강화는 "2페이즈 / 3페이즈". 각 보스 끝의 **뺌**은 다른 보스와 겹치는 공격.

### 5.1 동굴 수호자 — 핵을 드러내라 (① + ⑧ 핵, ③ 기둥)

- **컨셉**: 마왕군 문양이 새겨진 핵으로 움직이는 바위 골렘(2장 "깨어난 수호자")
- **고유**: 낙석이 남긴 **바위 기둥**이 탄을 막고, **돌진이 기둥에 박히면 2초 기절, 가슴 바위가 떨어져 핵이 드러난다**(발탄의 부위 파괴, 콜게라의 약점). 드러난 핵은 1.5배로 맞는다. 첫 보스라 "보스를 이용하는 법"을 가르친다
- **전환**: 2페이즈 핵에 금이 가 빛이 샌다 + 기둥 둘. 3페이즈 천장이 흔들려 돌가루. 첫 보스라 템포는 한 단 약하게(예고 ×0.9·×0.8)

|---|---|---|---|---|
| 내려찍기 | 전부 | ① | 남김 | 좌·우 2연 / 3연, 끝에 작은 고리 |
| 휩쓸기 | 전부 | ① | 남김 | — / 왕복 |

| 돌 파편 | 전부 | ③ | 남김, **기둥 뒤로 숨으면 막힌다** | 14발 / 18발 두 물결(돌 폭풍을 합침) |
| 돌진 | 2~3 | ⑧ | **바꿈**: 기둥에 박히면 기절, 핵 드러남. 기둥을 등지고 서서 유도 | — / 꺾어 2연 |
| 바위 솟기 | 2~3 | ③ | **바꿈**(지진): 발밑에서 기둥이 솟는다(처음엔 피해 없음) | 하나 / 둘씩 |
| 충격파 | 2~3 | ① | 남김 | — / 안 → 밖 두 겹 0.5초 차 |

뺌: 여진(충격파와 같음), 천장 붕괴(핵 폭주로).

### 5.2 개미귀신 — 끌려드는 모래 (① + ⑤ 끌기, ④ 땅속)

- **컨셉**: 광산 갱도 밑 모래 구덩이의 포식자(곁이야기 "갱도 깊은 곳")
- **고유**: **개미지옥 끌림**(걸음의 30%로 가운데로, 가운데에서 턱) + **모래 둔덕**으로 보이는 땅속 이동. 라단처럼 "끌어당긴 뒤 바로 문다"
- **전환**: 2페이즈 아레나 가운데가 꺼져 큰 개미지옥(3칸)이 늘 남는다(라단 2페이즈의 끌기 + 연타). 3페이즈 둘레에 작은 구덩이 셋

### 5.3 수정 거미 여왕 — 빛의 순서를 기억하라 (① + ⑧ 수정, ⑨ 순서, ⑭ 막간)

- **고유**: 여왕이 꽂은 **수정**이 **차례로 빛나고, 그 순서대로 터진다**(메이븐의 기억 놀이를 작게: 1페이즈 둘, 2페이즈 셋, 3페이즈 넷). 수정은 때려 부술 수 있다(아제오스의 수정). 3페이즈 전환에 **알 막간**(발탄의 구슬): 여왕이 천장에 매달려 맞지 않고 알 다섯이 깔린다. 12초 안에 깨지 못한 알은 3페이즈에 새끼로 나온다
- **아라네와 다른 점**: 아라네는 밟는 바닥(거미줄), 여왕은 서 있는 수정과 순서

### 5.4 물살 뱀 — 파도의 틈 (① + ④ 잠수, ⑪ 파도 벽, ③ 차오르는 물)

- **고유**: **잠수**(V자 물결이 보인다) + **틈 있는 파도 벽**(엔터 더 건전의 탄 벽, 아제오스의 좁혀 오는 번개처럼 양옆에서 좁혀 오기도). 3페이즈엔 **물이 차서** 가장자리 2칸이 얕은 물(걸음 75%)
- **전환**: 2페이즈 웅덩이 둘. 3페이즈 가장자리가 잠긴다(레이스처럼 아레나 위협이 늘 있음)

### 5.5 모르그 — 없는 군대의 지휘관 (① + ⑧ 군기, ⑪ 대열, ⑫ 표적, ⑭ 막간)

- **컨셉**: 왕의 오른팔이던 마족 장군. 미쳐서 없는 군대에 호령한다
- **고유**: **군기**를 꽂으면 그 둘레 4칸에서 부하가 강해지고 호령이 군기 쪽으로 떨어진다. **부수면 모르그가 1.5초 비틀거린다**. **환영 창병 대열**이 틈을 두고 아레나를 가로지른다. 호령 표적(FFXIV의 가까울수록 아픈 공격): 표적이 된 사람 둘레에 화살비, 다른 사람과 떨어져야 한다(혼자면 그냥 피하기)
- **3페이즈 전환 막간**(데드 셀 왕의 손, 데스 도어의 문 황소 길): 모르그가 군기 뒤로 물러나 15초 동안 환영 군단이 세 물결로 돌격한다. 군기를 부수면 막간이 바로 끝난다

### 5.6 왕관의 망령 — 진짜는 왕관이 빛난다 (① + ⑥ 분신, ④ 순간이동, ② 웅덩이)

- **전환**: 2페이즈 안개가 되어 흩어졌다 셋으로 모인다. 3페이즈 웅덩이 넷

| 개미귀신 | ⑤④ | 끌어당긴 뒤 무는 개미지옥, 둔덕이 멈춘 곳에서 솟는다 | M |
| 수정 거미 여왕 | ⑧⑨⑭ | 수정이 빛난 순서대로 터진다, 알 막간 | L |
| 물살 뱀 | ④⑪③ | 잠수 V물결, 틈 있는 파도, 좁혀 오는 물벽 | L |
| 모르그 | ⑧⑪⑫⑭ | 부술 군기, 환영 대열, 표적 화살비, 군단 막간 | L |
| 왕관의 망령 | ⑥④② | 금색 왕관이 진짜, 웅덩이로 퍼지는 번개 | L |
| 용암 거인 | ②③⑬ | 남는 용암·식은 바위·차오르는 용암, 심장 과열 | M(②③ 뒤) |
| 공허의 군주 | ⑤⑮⑨⑫⑭ | 끌고 미는 중력, 거꾸로 다시 터지는 되감기, 별 미로 막간 | L |
| 그룸 | ⑯⑬ | 붙어서 ↔ 벽 속에서 멀리, 광맥 먹으면 분노 | M |
| 시구레 | ⑦⑩ | 오연 발도, 때리면 안 되는 납도 자세, 늦은 거합, 결계 | S |
| 발두인 | ⑩⑦ | 꼭대기에서 멈추는 망치, 투구를 벗은 뒤 색 표지 | S |
| 아라네 | ②⑤⑫ | 늘어나면 끌려가는 실, 연타 수 증가, 거미줄 커튼 | S~M |

## 7. 만들기 규모

### 7.1 엔진에 새로 필요한 공용 틀

| 틀 | 무엇 | 계열 | Core | 화면 | 크기 |
|---|---|---|---|---|---|
| **T1 페이즈 템포** | 예고·쉼·이동을 페이즈마다 곱함(바닥 지킴), 전환 무적 | 전부 | `World.Boss.Tempo` 넓힘, `bosses.csv` `tempo` 열 | 없음 | S |
| **T2 강화·연계·지연** | `boss_attacks.csv` 새 열 `boost`(예: `2:count+1,tele*0.8;3:count=5,again=0.3`), `combo`(이어 쓸 공격 목록), `hold`(예고 끝을 늦추는 범위와 단서 박자) | ⑩, 강화판 | 시트 + 공격 시작 | 단서 번쩍임 | M |
| **T3 지형과 물체** | `pool`을 넓혀 용암·물·식은 바위, 서 있는 물체(기둥·수정·군기·광맥: 막음·생명력·부딪히면 보스 기절), 아레나 둘레 장판(차오름·결계) | ②③⑧ | `World.Pools` 넓힘, 새 `BossProp` | 장판·물체 | L |
| **T4 끌기·밀기·실** | 자리·고리·사람 사이의 힘 | ⑤⑫ | 플레이어 이동에 외력 | 흐름·실 | M |
| **T5 숨기·솟기** | `burrow` 넓힘: 표시가 쫓다 멈춘 자리, 마지막 자리, 벽 속 | ④⑯ | 숨은 동안의 길 | 둔덕·물결 | M |
| **T6 분신** | 체력 1, 몫 ×0.4, 본체를 시차로 따라 함 | ⑥ | 분신 몸, 스냅숏 | 흐린 본체 + 금 왕관 | L |
| **T7 벽·대열 탄** | 가로 줄(틈 지정), 양옆에서 좁혀 오기 | ⑪ | `trail` 넓힘 | 파도·창병 | S |
| **T8 순서·되감기** | 예고 묶음을 순서대로(빛 → 터짐), 지난 예고 기록 재생 | ⑨⑮ | 예고 기록(5초) | 흐린 보라 다시 그리기 | M |
| **T9 상태·막간** | 분노(받은 피해·먹기로 켜짐, 시간, 끝나면 빈틈), 막간(보스 무적, 할 일 끝나거나 시간 다 되면 끝) | ⑬⑭ | 보스 상태 둘 | 분노 빛, 막간 안내 | M |
| **T10 표지 = 대처** | 경고 표지 종류(벚꽃·붉음·푸름), 필살기 이름 표시 | ⑦ | `warn` 값 더함 | 표지 그림, 이름 띠 | S |

- 통신: 지형 물체·분신은 스냅숏 한도(지금 16) 안에 보스마다 여섯까지. `Protocol.Version` 올림
- 봇(`BossSim`·`BotPilot`): 지형 피하기, 거슬러 걷기, 진짜 분신, 물체 부수기, 순서 기억, 반격 자세에 때리지 않기를 배워야 균형을 잰다
- 시험: 강화판 예고 바닥, 연타 간격 > 구르기 재사용, 필살기 1.2초 이상, 한 번에 두 겹, 새 계열은 처음 한 번 피해 없음, **한 계열 세 보스까지**(시트 검사)

### 7.2 묶음과 순서 제안

| 묶음 | 내용 | 그림·소리 (Fable 하위 작업) |
|---|---|---|
| **R1 템포·강화·표지** | T1 + T2 + T10. 시구레·발두인·아라네(실 빼고)의 강화표, 앞 아홉의 "남김" 줄 강화 | 시구레 납도 자세·벚꽃 표지, 발두인 투구 벗기·색 표지, 필살기 이름 띠 → **Fable** |
| **R2 바닥·물체·상태** | T3 + T9. 용암 거인(사람 예시) → 동굴 수호자 → 그룸 | 용암·식은 바위·분출구·과열 빛, 기둥·드러난 핵, 광맥, 끓는 소리 → **Fable** |
| **R3 끌기·숨기·벽** | T4 + T5 + T7. 개미귀신 → 물살 뱀 → 아라네의 실 | 끌림 흐름, 둔덕, V물결, 파도 벽, 실 → **Fable** |
| **R4 분신·순서·막간** | T6 + T8 + 막간. 수정 거미 여왕 → 모르그 → 왕관의 망령 → 공허의 군주 | 수정 빛 순서, 알, 군기·환영 창병, 분신·금 왕관, 되감기·별 미로·중력 반전 → **Fable** |

- 묶음마다 새 세션. 코드(규칙·시험·화면 배치)는 그 세션, 그림·소리만 Fable 하위 세션
- 묶음마다 `--hits`, 봇 시드 1~5, `Client/Playtest.cs` 장면(보스마다 "2·3페이즈 강화판" 한 장면) + `sweep.js --only patterns`
- 대략: R1 한 세션, R2·R3 각 한두 세션, R4 두 세션

## 8. 사람이 고를 것

1. 계열 나누기(4.1 표)가 컨셉에 맞는지. 특히 여왕의 **기억 순서**, 공허의 **되감기**, 그룸의 **거리 바꾸기**, 아라네의 **실 잇기**
2. **막간**(여왕·모르그·공허)을 넣을지. 맞지 않는 시간이 생겨 싸움이 길어진다
3. 템포(예고 ×0.85/×0.75, 쉼 ×0.75/×0.6)가 맞는지, 더 세게(×0.8/×0.65)인지
4. "뺌"이 지나친지(공허 열다섯 → 열, 용암 열넷 → 열)
5. 순서: R1부터(빠르게 체감) 또는 R2부터(용암 거인 먼저)
