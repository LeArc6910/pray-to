# 아이템과 루팅

아이템이 어떻게 만들어지는지와 데이터 시트 작성법이다. 코드는 `Assets/_Project/Scripts/Core/Items`와 `Core/Stats`, 데이터는 `Assets/_Project/Data/Loot/*.csv`에 있다.

## 아이템이 만들어지는 순서

1. **베이스**: 아이템 레벨이 도달한 가장 높은 단계(`level`)의 베이스만 떨어진다. 레벨 25면 level 20(미스릴) 베이스만 나온다. 보스를 잡아 다음 단계가 열리면 이전 장비는 더 이상 바닥에 떨어지지 않는다.
2. **등급**: 아래 표의 가중치로 고른다. 줍는 사람의 `아이템 희귀도`가 +N%면 일반을 뺀 등급의 가중치가 (100+N)%가 된다.
3. **고유 능력치**(`implicit`): 베이스에 적힌 범위 안에서 굴린다.
4. **접두사·접미사**: 등급마다 정해진 개수만큼 뽑는다. 아이템 레벨 이하에서 열린 티어 전부를 놓고 `weight` 비율로 고른다. 같은 접사는 한 번만 붙고, 접두사와 접미사는 각각 최대 개수가 있다.
5. **소켓**: 40% 확률로 하나씩 더 생기고, 베이스의 최대 소켓 수에서 멈춘다. 소켓 3개짜리 베이스라면 0개 60%, 1개 24%, 2개 9.6%, 3개 6.4%다.

| 등급 | 가중치 | 접사 수 | 접두사·접미사 각각 최대 |
|---|---|---|---|
| 일반 | 700 | 0 | 0 |
| 고급 | 220 | 1~2 | 1 |
| 희귀 | 70 | 3~4 | 2 |
| 영웅 | 10 | 5~6 | 3 |

이 숫자들은 코드의 `LootConfig`에 있다.

## 룬과 룬워드

- 룬은 따로 떨어지는 아이템이다. 소켓에 끼우면 무기, 방어구, 장신구 중 어디에 끼웠는지에 따라 다른 능력치를 준다.
- 끼운 룬은 모루에서 강화 정수 1개를 들여 모두 뺄 수 있다(2026-11-03, 아래 "장비 다듬기"). 빼면 룬워드도 풀린다.
- **룬워드**: **일반 등급** 아이템의 소켓 수와 룬 수가 정확히 같고, 정해진 순서대로 끼우면 룬 자체 능력치에 더해 추가 보너스가 붙는다. 일반 등급으로 제한해서 소켓 달린 일반 아이템도 주울 이유가 생긴다.

## 능력치 계산

```
최종값 = (기본값 + 고정 수치 합) × (1 + 증가% 합) × 증폭마다 (1 + N%)
```

- **증가**는 서로 더한 뒤 한 번 곱한다. **증폭**은 하나하나 따로 곱한다. 증폭은 클래스 패시브처럼 드문 효과에 쓴다.
- 태그가 붙은 능력치는 그 태그가 **모두** 있는 공격이나 스킬에만 적용된다. `Fire:Damage+20%`는 화염 스킬에는 적용되고 그냥 검을 휘두를 때는 적용되지 않는다.
- 무기 베이스의 `tags`가 그 무기 기본 공격의 태그이고, 기본 공격의 모양(휘두르기, 화살, 마법 탄)도 정한다(`Docs/Combat.md`). 클래스 조합은 스킬 태그와 이 태그 능력치들로 만든다(`Docs/Classes.md`).
- 무기 세 계열의 성격. 스킬 피해도 무기 피해에 비례하므로 무기 고르기가 빌드의 일부다
  - **검**: 무기 피해가 가장 높다. 붙어서 싸워야 한다
  - **활**: 무기 피해가 검의 약 4분의 3이고 공격 속도 5% 증가. 멀리서 쏜다
  - **지팡이**: 무기 피해는 활과 같고, 마법 피해 증가(30~45%)가 커서 마법 스킬이 가장 세다. 대신 공격 속도가 15% 느리다. 처음에는 활보다 피해가 낮고 마법 증가도 10%뿐이어서 화염 마법사도 검을 드는 쪽이 셌다. 원거리 기본 공격을 넣으면서(2026-10-29) 지금 숫자로 바꿨다

## 시트

`#`로 시작하는 줄은 주석이다. 칸 안에 여러 값을 적을 때 능력치는 `;`, 그 밖의 값은 `|`로 나눈다.

### item_bases.csv

| 열 | 내용 |
|---|---|
| id | 영문, 숫자, `_`, `-` |
| name | 화면에 보이는 이름 |
| slot | `weapon`, `helmet`, `chest`, `boots`, `ring`, `amulet` |
| level | 단계. level이 같은 줄끼리 한 단계다 |
| tags | 무기 공격의 태그. 예: `melee`, `ranged`, `magic` |
| implicit | 고유 능력치. 범위를 쓸 수 있다 |
| sockets | 최대 소켓 수 (0~6) |
| weight | 같은 단계 안에서 나올 비율 |
| tool | (선택) 도구 종류. 지금은 `pickaxe`(곡괭이, `weapon` 슬롯만)뿐이다. 곡괭이를 손에 들어야 바위를 캔다(`Docs/Crafting.md`). 비우면 보통 장비 |
| legendary, chance | (선택) 전설 아이템이면 떨어뜨리는 보스 id와, 그 보스를 잡을 때 싸운 사람 한 명마다 떨어질 확률(%). 전설은 무작위 드랍에 나오지 않는다 |
| require | (선택) 착용 레벨. 비우면 보통 장비는 `level − 5`(1 아래로는 안 간다), 전설은 `level` |

### affixes.csv

한 줄이 티어 하나다. 같은 id의 두 번째 줄부터는 `kind`, `name`, `slots`를 비워도 된다. 티어는 level이 올라가는 순서로 적고, 티어끼리 능력치 종류(능력치·고정/증가/증폭·태그)가 같아야 한다.

| 열 | 내용 |
|---|---|
| id | 접사 id |
| kind | `prefix` 또는 `suffix` |
| name | 이름. 고급 아이템은 "접미사 접두사 베이스" 순서로 이름이 붙는다 (신속의 날카로운 구리 검) |
| slots | 붙을 수 있는 슬롯. `armor`는 helmet\|chest\|boots, `jewelry`는 ring\|amulet |
| level | 이 티어가 열리는 아이템 레벨 |
| weight | 뽑힐 비율 |
| modifier | 능력치 하나. 범위를 쓸 수 있다 |

### runes.csv

`id, name, level, weight, weapon, armor, jewelry`. 뒤의 세 칸은 각각 무기, 방어구, 장신구에 끼웠을 때의 능력치다. 범위 없이 하나의 값으로 적는다.

### consumables.csv

`id, name, level, heal, seconds, cooldown, weight, description, buff, buff_seconds`. 마시거나 먹는 소모품이다(`Docs/Combat.md`의 회복 절, 음식은 `Docs/Farming.md`).

| 열 | 내용 |
|---|---|
| heal | 채우는 양. 최대 생명력의 %. `buff`가 있으면 0도 된다 |
| seconds | 그만큼을 몇 초에 걸쳐 채우는지 |
| cooldown | 마신 뒤 모든 소모품을 다시 쓸 수 있을 때까지(초) |
| level, weight | 드랍 레벨이 level 이상일 때 나오고, 그중 weight 비율로 고른다 |
| description | 가방 창에 보이는 설명 |
| effect | (선택) 그 밖에 하는 일. 지금은 `recall`(침대나 시작 지점으로 귀환, `Docs/Crafting.md`)뿐이다. 있으면 heal이 0이어도 되고 생명력이 가득해도 쓴다 |
| buff, buff_seconds | 음식이 거는 능력치(장비와 같은 문법, 범위는 안 됨)와 그 시간(초). 둘 다 채우거나 둘 다 비운다. 이 열이 없는 옛 시트도 읽는다 |

### runewords.csv

`id, name, slots, runes, modifiers`. `runes`는 끼워야 하는 순서대로 `|`로 나눠 적는다. 그 슬롯에 소켓이 그만큼 있는 베이스가 없으면 오류가 난다.

## 능력치 문법

| 쓰는 법 | 뜻 | 화면 표시 |
|---|---|---|
| `Damage+5` | 고정 수치 | 피해 +5 |
| `Damage+3~5` | 범위. 떨어질 때 한 번 굴린다 | 피해 +4 |
| `Damage+20%` | 증가 | 피해 20% 증가 |
| `MoveSpeed-5%` | 감소 | 이동 속도 5% 감소 |
| `Damage*20%` | 증폭 (따로 곱함) | 피해 20% 증폭 |
| `Fire:Damage+20%` | 태그 | 화염 피해 20% 증가 |
| `Melee&Fire:Damage+20%` | 태그 여러 개 (모두 있어야 적용) | 근접 화염 피해 20% 증가 |

- 능력치: `MaxHealth` 최대 생명력, `HealthRegen` 생명력 재생, `Armor` 방어도, `MoveSpeed` 이동 속도, `Damage` 피해, `AttackSpeed` 공격 속도, `CritChance` 치명타 확률, `CritDamage` 치명타 피해, `MiningSpeed` 채굴 속도, `ItemRarity` 아이템 희귀도. `CritChance`와 `CritDamage`는 고정 수치 자체가 %다
- 태그: `Melee` 근접, `Ranged` 원거리, `Magic` 마법, `Summon` 소환, `Fire` 화염, `Cold` 냉기, `Lightning` 번개

## 조정하는 법

1. 시트를 고친다.
2. `dotnet test DevTools/Game.Core.Tests`를 실행한다. 시트에 문제가 있으면 `affixes.csv 12행: ...`처럼 위치를 알려준다.
3. 시뮬레이션으로 결과를 본다.
   - `dotnet run --project DevTools/CoreSandbox -- --loot 25 10000`: 레벨 25 아이템 1만 개의 등급, 소켓, 접사, 티어, 룬 분포
   - `dotnet run --project DevTools/CoreSandbox -- --progression`: 아이템 레벨별 희귀 무기 피해와 갑옷 방어도 (계단 모양 확인)
   - `dotnet run --project DevTools/CoreSandbox -- --item 25 7`: 레벨 25 아이템 하나 (시드 7)
   - `--loot`와 `--item`에 `--rarity 100`을 붙이면 아이템 희귀도 +100%로 굴린다

지금 데이터의 계단은 희귀 무기 피해 중앙값 기준으로 5 → 10 → 19 → 36이다. 단계마다 약 2배씩 오른다.

## 드랍과 가방 (M3b)

- **몬스터 드랍**: 죽을 때 `monsters.csv`의 `drop_chance`% 확률로 아이템 하나, `rune_chance`% 확률로 룬 하나를 떨어뜨린다. 아이템 레벨은 몬스터 레벨과 **진행 레벨** 중 높은 쪽이다. 마지막 일격을 넣은 플레이어의 `아이템 희귀도`가 등급 확률에 붙는다.
- **보스 보상**: 보스는 싸운 사람 한 명마다 `drop_count`개의 아이템과 `rune_count`개의 룬을 떨어뜨린다. 아이템은 `drop_level` 레벨이고 등급은 최소 `drop_rarity`다. 동굴 수호자는 1인당 레벨 10(철 단계) 희귀 이상 아이템 2개와 룬 1개를 준다.
- **진행 레벨**: 처음에는 1이다. 보스를 잡으면 그 보스의 `drop_level`까지 올라가고 내려가지 않는다. 그래서 첫 보스를 잡은 뒤에는 슬라임도 철 장비를 떨어뜨린다. 계단식 성장이 여기서 실제로 이어진다.
- **바닥 아이템**: 떨어진 자리 근처 바닥에 5분 동안 남는다. 위로 걸어가면 자동으로 줍는다. 바닥에는 최대 200개까지 있고, 넘으면 오래된 것부터 사라진다. 누구나 주울 수 있다(협동 중 나눠 갖기는 아직 따로 없다).
- **가방**: 아이템 24칸이다. 룬과 소모품은 칸을 차지하지 않고 종류별로 쌓인다. 가방이 차면 아이템은 바닥에 남고 룬과 소모품은 계속 주워진다.
- **소모품 드랍**: 몬스터는 `potion_chance`%, 보스는 1인당 `potion_count`개. 어떤 소모품인지는 드랍 레벨 이하의 소모품 중 `weight` 비율로 고른다.
- **재료 드랍**: 몬스터는 `material`을 `material_chance`%, 보스는 1인당 `material_count`개. 재료와 제작은 `Docs/Crafting.md`. 시트 `materials.csv`, `recipes.csv`도 이 폴더에 있다.
- **가방에서 할 수 있는 일** (Tab 또는 I)
  - 장착: 원래 끼고 있던 아이템은 그 자리로 들어온다.
  - 벗기: 가방에 빈 칸이 있어야 한다.
  - 룬 끼우기: 룬을 고르고 아이템의 [끼우기]를 누르면 첫 번째 빈 소켓에 들어간다. 낀 아이템에도 넣을 수 있다.
  - 버리기: 바라보는 쪽 1.2칸 앞 바닥에 떨어뜨리고, 5초 동안은 다시 줍지 않는다.
- 모든 명령은 호스트가 확인한 뒤 처리하고, 결과는 인벤토리 메시지로 돌아온다.

## 전설 아이템과 착용 레벨 (2026-11-02)

- **전설 아이템**: 보스마다 둘씩, 이름과 능력치가 정해진 고유 장비다(`item_bases.csv`의 `legendary` 열). 보스를 잡으면 싸운 사람마다 각각 `chance`%(지금 25%) 확률로 떨어진다. `implicit`의 능력치를 범위 안에서 굴리고, 접사는 없고, 룬 소켓은 모두 열려 있다. 금빛 아이콘에 주황 글씨, 등급 이름은 "전설"이다
  - 동굴 수호자: 수호자의 바위망치(검, 피해와 방어도, 느린 공격), 수호자의 심장석(목걸이, 생명력·재생·방어도)
  - 수정 거미 여왕: 여왕의 독니(활, 빠른 공격과 치명타), 수정 왕관(투구, 마법 피해·치명타 피해)
  - 용암 거인: 거인의 불씨(화염 지팡이), 용암 거인의 갑주(갑옷, 생명력·재생)
  - 공허의 군주: 공허 군주의 홀(번개 지팡이), 공허의 고리(반지, 생명력·피해·치명타·공격 속도)
- **레벨**: 캐릭터는 경험치로 레벨 1~50이 된다. 레벨 N까지 경험치 `14 × (N − 1)²`(5레벨 224, 15레벨 2744, 25레벨 8064). 레벨마다 최대 생명력 +2
  - 몬스터를 잡으면 16타일 안에 살아 있는 모두가 각자 `3 × L + 6`을 받는다. L은 몬스터 레벨과 진행 레벨 중 높은 쪽이라서 드랍처럼 보스를 잡을 때마다 오른다(처음 9~15, 동굴 수호자 뒤 36, 여왕 뒤 66, 거인 뒤 96)
  - 보스는 싸운 사람 모두에게 `30 × drop_level`(동굴 수호자 300, 여왕 600, 거인 900)
- **착용 레벨**: 그 레벨이 되어야 입는다. 구리 1, 철 5, 미스릴 15, 흑요석 25, 공허 35, 전설은 그 단계(10, 20, 30, 40). 가방의 [장착] 대신 "Lv5"처럼 필요한 레벨이 보이고, 호스트도 거절한다. 벗는 건 언제든 된다
- **예전 캐릭터**: 레벨이 생기기 전 저장본(캐릭터 형식 1)은 가진 장비를 모두 입을 수 있는 레벨에서 시작한다
- HUD에 "Lv 7 (34%)", 레벨이 오르면 가운데 배너와 소리, 머리 위에 "Lv 7"

## 장비 다듬기 (2026-11-03)

사람이 고른 작업 2번이다. 모루 곁에서 장비를 강화하고, 분해하고, 룬을 빼고, 접사를 다시 굴린다. Craft to Exile 2처럼 마음에 드는 장비를 오래 다듬어 쓰게 하려는 것이다. 코드는 `Scripts/Core/Simulation/World.Refining.cs`에 있다.

- **모루**(작업대: 철 주괴 5, 돌 6): [놓기]로 세운다. 곁(2.5칸 안)에 서면 가방 장비 탭의 장비마다 [다듬기]가 생긴다. 누르면 탭 맨 위에 그 장비로 할 수 있는 일과 비용이 나온다. 입은 장비도 다듬을 수 있다(분해만 빼고)
- **강화 정수**: 장비를 분해하면 나온다. 강화와 접사 다시 굴리기에 쓴다
- **강화**(+1~+5): 한 단계마다 장비의 기본 능력치(바탕의 고정 능력치, 무기 피해와 방어구 방어도 등)가 10%씩 오른다(올림, 최소 1). +5면 1.5배다
  - 비용: 정수를 단계×2개(+1에 2, +5에 10, 모두 30). 조합법으로 만드는 장비는 거기에 그 조합법에서 가장 많이 드는 재료(철 검이면 철 주괴)를 단계만큼 더 든다(모두 15). 조합법이 없는 장비(전설 등)는 정수만 단계×3개
  - 이름 앞에 "+3"처럼 붙는다. 강화 단계는 저장본과 통신에서 희귀도 바이트의 위쪽 4비트에 들어간다. 그래서 형식을 바꾸지 않았고, 옛 저장본은 +0으로 읽힌다
- **분해**: 가방의 장비를 없애고 정수를 준다. 일반 1, 고급 2, 희귀 4, 영웅 7, 전설 12개에 아이템 레벨 10마다 1개를 더한다. 강화에 든 정수는 절반을 돌려준다. 끼워 둔 룬은 가방으로 돌아온다
- **룬 빼기**: 정수 1개로 모든 룬을 가방으로 돌려받는다. 룬워드는 풀린다
- **접사 다시 굴리기**: 희귀도와 아이템 레벨은 그대로 두고, 그 희귀도가 받는 수만큼 접사를 새로 굴린다. 비용은 정수 고급 3, 희귀 5, 영웅 8개다. 일반과 전설은 접사가 없어 굴리지 않는다
- 통신: 인벤토리 명령 `Upgrade`, `Salvage`, `Unsocket`, `Reroll`(아이템 id)을 쓴다. 호스트가 모루 곁인지, 비용이 있는지 본다

## 균열 전설, 세트, 5단계 접사 (2026-11-04)

- **5단계 접사**: 모든 접사에 아이템 레벨 50부터 붙는 5단계(T5)가 있다. 수치는 4단계의 1.35배쯤이고 무게는 절반이다. 보스는 레벨 40까지만 떨어뜨리므로 **5단계 이상의 공허 균열**(아이템 레벨 = 월드 드랍 레벨 + 단계×2)에서만 나온다
- **균열 전설**: `item_bases.csv`의 `legendary`가 `rift`인 다섯. 균열을 깨면 각각 chance% + 단계마다 3%(`World.RiftLegendaryPerTier`)로 떨어진다. 착용 레벨 45
  - 공허 순례자의 두건·옷·신(세트), 균열 칼날(근접 무기), 균열의 눈(목걸이)
- **세트**: 새 시트 `sets.csv`와 `item_bases.csv`의 새 `set` 열. 같은 세트를 여럿 입으면 그 수만큼의 보너스가 붙는다(`PlayerStats.From`). 장비 설명에 "세트: 이름"과 개수별 보너스가 보인다
  - 공허 순례자: 2개 피해 15% · 생명력 +40, 3개 치명타 확률 +6 · 치명타 피해 +40 · 이동 속도 8%

### sets.csv

| 열 | 내용 |
|---|---|
| id | 세트 id(`item_bases.csv`의 `set`이 가리킨다) |
| name | 세트 이름(첫 줄에만) |
| pieces | 몇 개를 입어야 하는지(2 이상). 한 세트가 여러 줄로 단계를 둔다 |
| modifiers | 그때 붙는 능력치(룬처럼 하나의 값으로) |
