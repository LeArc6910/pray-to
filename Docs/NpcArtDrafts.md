# NPC 초상화·마을 도트와 몬스터 다시 그리기 시안 (2026-11-29)

사람 요청(2026-11-29): NPC 마을 도트와 대화 초상화를 로컬 AI로 개선한다. 초상화는 픽셀을 낮게 뽑지 말고 일반 2D 캐릭터 그림 느낌에 도트 느낌만 살짝 더한다. 오브젝트와 일반 몬스터도 품질이 낮은 것을 골라 로컬 AI로 다시 그린다(예: 균사 어미). 사람이 자는 동안 확인이 필요 없는 일만 하고, 방향 확인은 남긴다(`CLAUDE.md` 큰 그림 작업은 작은 시안을 먼저 보인다).

## 한 일

- 도구와 모델은 보스 때와 같다(`Docs/ArtSources.md` 로컬 AI로 보스 그림): Z-Image-Turbo + 도트 LoRA, `comfy.py t2i`, 게임 크기로 줄이기는 `to_sprite.py`. 헤드리스 포트 8194, `gpu-lock.json`을 잡고 끝나면 끄고 지웠다. 새로 받은 모델은 없다
- 프롬프트: `DevTools/ArtImport/LocalAi/drafts_2026-11-29/`(`p_*` 초상화, `s_*` 마을 도트, `m_*` 몬스터, `o_*` 설치물)
- **초상화**: 촌장·미나·대장장이·보라 두건 상인 넷을 도트 LoRA 0.4와 0.8로 시드 셋씩(24장). 각 장을 그대로 / 256px·64색 / 160px·40색으로 줄여 "살짝 도트"의 정도를 비교한다. 프롬프트에 "dialogue box"를 넣으면 말풍선이 그려져서 빼고 "no speech bubble"을 넣었다
- **마을 도트**: 같은 셋을 LoRA 1.0으로 시드 셋씩, 24px 키로 줄인 모습까지
- **몬스터 점검**: 그림 미리보기(Actions `art-preview`의 `sheet.png`)에서 보통 몬스터 63종을 보고, 작은 몬스터는 지금 그림이 크기에 비해 충분하고 큰 몬스터(l·xl) 중 덩어리가 단순한 아홉을 골랐다: 균사 어미, 갓 거인, 눈 거인, 큰 모래 지렁이, 신전 수호 석상, 정동 골렘, 잿불 대장장이, 공허의 문지기, 용암 투석꾼. 시드 셋씩, 지금 그림과 같은 크기(30~58px)로 줄인 모습까지
- **오브젝트 점검**: 생물군계 소품(`props_*.png`)과 설치물(`flat/objects.png`)은 고르게 다듬어져 있다. 설치물 여섯을 시험으로 그려 16px로 줄여 보니 뭉개져서 지금 코드 그림이 낫다. 바꾸지 않기를 권한다

## 사람이 고를 것

로컬 세션의 고르기 페이지(`.claude/launch.json`의 `art-review`, 포트 8766)에서 세트마다 하나: 초상화의 화풍(LoRA 세기와 도트 정도), 마을 도트의 방향, 몬스터 아홉의 후보, 설치물을 둘지. "다 별로"와 "지금 그대로"도 고를 수 있다.
